# 補間と近似

**これは章2の続きではない。章3（求積）の前提としてここに置いてある。**
章3は Newton–Cotes 型を「\\(f\\) を多項式で補間して、その多項式を厳密に積分する」と定義し、
Runge 現象を根拠に高次を捨てる。その土台がこの章である。
章8bの誤差評価（Céa の補題のあとに入る補間誤差）も同じ道具を使う。

## 多項式補間は一意である

相異なる \\(n+1\\) 点を通る \\(n\\) 次以下の多項式は**ただ一つ**存在する。
存在は下の構成で示せるし、一意性は「差が \\(n+1\\) 個の零点を持つ \\(n\\) 次多項式」だから 0、で終わる。

一意なので、**書き方の違いは表現の違いにすぎない。** それでも書き方で性質が変わる。

### Lagrange 形式

\\[
p(x) = \sum_{i} f(x_i)\,\ell_i(x), \qquad
\ell_i(x) = \prod_{j \neq i}\frac{x - x_j}{x_i - x_j}
\\]

\\(\ell_i(x_j) = \delta_{ij}\\) なので、通ることが式を見ただけで分かる。
概念的には最も明快だが、素朴に評価すると \\(O(n^2)\\) かかり、
**点を1つ足すと全部作り直し**になる。

### Newton 形式と差分商

\\[
p(x) = f[x_0] + f[x_0,x_1]\,(x-x_0) + \cdots + f[x_0,\ldots,x_n]\prod_{i<n}(x-x_i)
\\]

係数は**差分商**の三角形の表から出る。

\\[
f[x_i] = f(x_i), \qquad
f[x_i,\ldots,x_{i+k}] = \frac{f[x_{i+1},\ldots,x_{i+k}] - f[x_i,\ldots,x_{i+k-1}]}{x_{i+k} - x_i}
\\]

**点を足すのが安い**（表に1行足すだけで、既存の係数は変わらない）。
評価も Horner 形で \\(O(n)\\) になる。実装するならこちら。

差分商には意味がある——\\(f\\) が \\(C^k\\) 級なら
\\(f[x_0,\ldots,x_k] = f^{(k)}(\xi)/k!\\) となる \\(\xi\\) が区間内に存在する。つまり**差分商は導関数の離散版**で、
点を近づける極限で Taylor 展開に一致する。

### Barycentric 形式

Lagrange を書き直すと、評価が \\(O(n)\\) で、しかも数値的に安定な形になる。
重み \\(w_i = 1/\prod_{j\neq i}(x_i - x_j)\\) を先に計算しておけば

\\[
p(x) = \left.\sum_i \frac{w_i}{x - x_i}f(x_i) \middle/ \sum_i \frac{w_i}{x - x_i}\right.
\\]

**Lagrange 形式が「遅くて不安定」というのは素朴な実装の話**で、
この形なら高次でも安定に評価できる。実用の多項式補間はこれである。

ただし**節点の配置が良い場合に限る。** 等間隔節点では重み \\(w_i\\) 自体が
指数的に散らばる（\\(n\\) が数十で \\(\max|w|/\min|w|\\) が \\(10^{17}\\) に達する）ので、
この形でも救えない。Chebyshev のような配置なら散らばりは \\(n\\) に対して緩やかにしか増えない。
次の節がまさにその話である。
（\\(x\\) が節点に一致すると 0 除算になるので、そこだけ分岐する。章0の話が顔を出す。）

## 補間誤差——この章の中心

\\(f\\) が \\(C^{n+1}\\) なら、各 \\(x\\) に対して区間内のある \\(\xi\\) が存在して

\\[
f(x) - p(x) = \frac{f^{(n+1)}(\xi)}{(n+1)!}\prod_{i=0}^{n}(x - x_i)
\\]

**この1本の式から、以降の話が全部出る。** 右辺が2つの因子の積になっているのが要点で、

- \\(f^{(n+1)}(\xi)/(n+1)!\\) は**関数側**の量。こちらは動かせない
- \\(\prod(x-x_i)\\) は**節点側**の量。こちらは節点の置き方で動かせる

章7の Koksma–Hlawka（\\(V(f) \cdot D_N^\*\\)）と同じ形の分離である。
「関数の性質」と「点の配置の性質」に分かれるので、点だけを良くすればよい。

### 高次は良くならない——Runge 現象

素朴には「\\(n\\) を上げれば \\((n+1)!\\) で割るから収束する」と思える。**しない。**

有名な反例が \\(f(x) = 1/(1+25x^2)\\) を \\([-1,1]\\) で**等間隔**に補間する場合で、
\\(n\\) を上げると端点付近の振動が**発散する**。原因は誤差の式の両方の因子である——
\\(f^{(n+1)}\\) が \\((n+1)!\\) より速く育ち、かつ等間隔節点の \\(\prod(x-x_i)\\) が
端で中央より桁違いに大きくなる。

これが章3で「次数を上げるのではなく区間を細かくする（合成）か、
節点の位置を変える（Gauss）」と書いた根拠である。

### Chebyshev 節点

\\(\prod(x-x_i)\\) の最大値を最小にする節点の置き方が分かっている。
\\([-1,1]\\) 上で

\\[
x_k = \cos\frac{(2k+1)\pi}{2(n+1)}, \qquad k = 0,\ldots,n
\\]

とすると \\(\prod(x-x_i)\\) は Chebyshev 多項式の定数倍になり、
その最大値は等間隔より劇的に小さくなる。**端に節点が密に寄る**のが特徴で、
Runge 現象が起きる場所を先回りして潰している。

同じ Runge 関数を Chebyshev 節点で補間すると、今度は \\(n\\) とともに収束する。
**関数を変えずに節点だけ変えて結果が逆転する**——誤差の式の分離が効いていることの直接の証拠である。

## スプライン——高次を諦める

もう一つの道は、次数を上げずに区間を細かくすることである。
区分的な低次多項式を、節点で滑らかに繋ぐ。

3次スプラインは各区間で3次多項式、節点で \\(C^2\\)（値・1階・2階が連続）。
自由度と条件を数えると、端点で条件が2つ足りない。これを埋める取り方が
**自然スプライン**（端で2階微分を0にする）、**固定端**（端の1階微分を与える）、
**not-a-knot** などである。

自然端と固定端では、連続条件を並べると**三重対角の線形系**になる
（not-a-knot だけは最初と最後の行の帯幅が1つ広がる）。つまり

> スプラインを作る = 章2の三重対角系を解く

補間が線形代数に落ちる。章8bの FEM でも同じ構造（局所台の基底 → 疎行列）が出る。

高次多項式との対比が要点である。**高次は大域的で振動し、スプラインは局所的で振動しない。**
ただし補間スプラインは B-spline と違って**有限台ではない**——1点を動かした影響は
節点ごとに \\(2-\sqrt3 \approx 0.27\\) 倍で指数的に減衰しながら全域に届く。
章8bの基底関数の有限台とは別の意味の「局所性」なので、混ぜないこと。

## Rust の言語機構

### 補間器を返す形

章3で「積分器を返す形」を考えることになるが、同じ問いがここに先に出る。

```rust
// 呼ぶたびに全部やる
fn interpolate(xs: &[f64], ys: &[f64], x: f64) -> f64 { todo!() }

// 前計算を持った補間器を作る
struct Newton { coeffs: Vec<f64>, nodes: Vec<f64> }
impl Newton {
    fn new(xs: &[f64], ys: &[f64]) -> Newton { todo!() }  // 差分商の表を作る
    fn eval(&self, x: f64) -> f64 { todo!() }             // Horner 形で O(n)
}
```

補間は**同じ節点で何度も評価する**のが普通なので、後者が自然である。
差分商の表や barycentric の重みは前計算に入る。
章7の `rustfft` のプランと同じ構造で、この本で何度も出てくる形である。

### 差分商の表をどう持つか

三角形の表を作るが、実は**最終的に要るのは対角（または最上段）だけ**である。

- 二次元の `Vec<Vec<f64>>` で素直に持つ——読みやすいが確保が多い
- 一次元配列を後ろから上書きしていく——表を潰しながら進める。確保が1本で済む

章2の in-place 分解と同じ「作業領域を潰しながら進む」形で、
借用の問題も同じように出る。

### 点を足せる API

Newton 形式の利点は「点を足せる」ことである。これを型に出すかどうかが判断になる。

`fn add_point(&mut self, x: f64, y: f64)` を生やすと利点が API に現れるが、
節点の重複（同じ \\(x\\) を2度足す）を防ぐ責任が生じる。差分商の分母がゼロになるからである。
章1の「失敗をどう返すか」がここにも出る。

### スプラインの端点条件

自然 / 固定端 / not-a-knot をどう選ばせるか。列挙型で受けるか、
別のコンストラクタにするか、型パラメータにするか。
**既定を持つべきか**も判断で、既定を置くと「知らずに自然スプラインを使う」が起きる。

## オラクル

補間は**厳密に当たる場合がある**ので、オラクルが強い。

| 入力 | 期待 |
|---|---|
| \\(n\\) 次以下の多項式を \\(n+1\\) 点で補間 | 元の多項式に**厳密に一致**（丸めの範囲で） |
| 節点上での値 | \\(p(x_i) = f(x_i)\\) が厳密 |
| \\(f(x)=1/(1+25x^2)\\)、\\([-1,1]\\)、等間隔 | Runge 現象。\\(n\\) を上げると端で発散 |
| 同じ関数、Chebyshev 節点 | \\(n\\) とともに収束 |
| 3次スプライン | 節点で値・1階・2階が連続 |

1行目が特に良い。**次数 \\(\le n\\) の多項式なら誤差の式の \\(f^{(n+1)}\\) がゼロ**なので、
補間誤差が理論上ちょうど 0 になる。実装の正しさを一発で確かめられる。
次数を \\(n+1\\) に上げた瞬間に誤差が出るところまで見ると、
章3の Gauss の「次数の壁」とまったく同じ形の実験になる。

不変量（`proptest` 向け）:

- 節点で値が一致する
- 補間は**線形**である——\\(f+g\\) の補間が、\\(f\\) の補間と \\(g\\) の補間の和になる
- Lagrange 基底の和が恒等的に 1（\\(\sum_i \ell_i(x) \equiv 1\\)）
- 節点の順序を入れ替えても同じ多項式（一意性の帰結。Newton 形式では係数が変わるので良い検査になる）
- スプラインの2階微分が節点で連続

## この章で決めること

1. Lagrange 形式で書くか Newton 形式か barycentric か。評価と構築のどちらを速くするか
2. 補間器を値として返すか、毎回計算するか。前計算に何を入れるか
3. 差分商の表を二次元で持つか、一次元を潰しながら進むか
4. 点を足す API を出すか。節点の重複をどう扱うか
5. スプラインの端点条件をどう選ばせるか。既定を置くか

## 完了条件

- **多項式を厳密に再現することを示す。** 次数 \\(\le n\\) では誤差が機械精度、
  \\(n+1\\) にすると誤差が出る——この壁を見る
- **Runge 現象を実際に出す。** \\(1/(1+25x^2)\\) を等間隔で補間し、
  \\(n\\) を上げると端点付近の誤差が増大することを示す
- **同じ関数を Chebyshev 節点で補間すると収束する**ことを示す。
  節点を変えただけで結果が逆転するのが眼目である
- 3次スプラインを作り、節点で \\(C^2\\) を満たすことを `proptest` で検査する。
  併せて、章2の三重対角系を実際に呼ぶ

## 既製クレートの扱い

補間・スプラインは小さなクレートが複数あるが集約していない。
自作の難度が低く、章3・章8bへの土台として自分で書く価値が高い領域である。
Chebyshev 多項式まわりは章3の Gauss 節点（Legendre 多項式の根）と地続きなので、
両方を同じ道具で扱えないかを考えるとよい。
