# 章4 常微分方程式

初期値問題

\\[
y'(t) = f(t, y(t)), \qquad y(t_0) = y_0
\\]

を数値的に解く。**Rust 的には「状態の型に対して generic にする」という問題が
最も綺麗に効く題材である。**

続けて章4bで確率微分方程式に進む。そちらでは**「収束次数」という概念自体が割れる。**

## 陽的解法

### Euler 法と、次数のずれ

\\[
y_{n+1} = y_n + h f(t_n, y_n)
\\]

Taylor 展開との差（局所打ち切り誤差）は \\(O(h^2)\\)。しかし
\\(t_0\\) から \\(T\\) まで積むと \\((T-t_0)/h\\) ステップ蓄積するので、大域誤差は \\(O(h)\\) になる。

**局所と大域で次数が1つずれる。** 章3の合成則で局所 \\(h^3\\) → 大域 \\(h^2\\) だったのと同じ構造である。
「\\(p\\) 次の解法」と言うときは大域誤差の次数を指す。

### Runge–Kutta と Butcher の障壁

RK4 は1ステップに \\(f\\) を4回評価して4次精度を得る。

\\[
\begin{aligned}
k_1 &= f(t_n, y_n) \\\\
k_2 &= f(t_n + h/2,\; y_n + h k_1/2) \\\\
k_3 &= f(t_n + h/2,\; y_n + h k_2/2) \\\\
k_4 &= f(t_n + h,\; y_n + h k_3) \\\\
y_{n+1} &= y_n + \frac{h}{6}(k_1 + 2k_2 + 2k_3 + k_4)
\end{aligned}
\\]

段数と次数は4まで一致する（1段1次、2段2次、3段3次、4段4次）。
**ここで一致は止まる。Butcher の障壁**により、5次を得るには6段が要る。
「評価回数を増やせば同じだけ次数が上がる」は4次までしか成り立たない。

RK4 が実用の既定になっている理由の一つがこれである。正確に言うと、
段数と次数の比が 1 になるのは \\(p = 1,2,3,4\\) で同率であり、
**比 1 を達成できる最高次数が 4 である。** \\(p \ge 5\\) では段数が次数を上回る。

### 埋め込み型と刻み幅制御

適応刻みには誤差の推定が要る。素朴には刻み \\(h\\) と \\(h/2\\) で計算して比べる
（章3の適応分割と同じ）が、その分だけ計算量が増える。

埋め込み型 Runge–Kutta は、**同じ \\(k_i\\) を使い回して次数の違う2つの解を作る。**
Dormand–Prince (RK45, `ode45` / `dopri5`) は7段から4次解と5次解を出し、
その差を誤差推定に使う。**推定がほぼタダで手に入る。**
しかも7段目は次ステップの1段目と一致する（FSAL）ので、
**\\(f\\) の評価は毎ステップ実効6回**——前述の Butcher の障壁（5次には6段）と同じ数が並ぶ。

**どちらの解を次に伝播させるかを決める必要がある。** `ode45` / `dopri5` は
**5次解のほうを伝播する**（local extrapolation という）。誤差推定は4次解との差から取るのに、
進めるのは5次解、という非対称な作りである。

推定誤差 \\(\varepsilon\\) と許容 \\(\text{tol}\\) から次の刻みを

\\[
h_{\text{new}} = h \cdot \text{safety} \cdot \left(\frac{\text{tol}}{\varepsilon}\right)^{1/(p+1)}
\\]

で決める。safety は 1 をわずかに下回る値にする。**\\(p\\) は伝播させる解の次数ではなく、
誤差推定が有効な側の次数**（`dopri5` なら 4、指数は \\(1/5\\)）である。

ここは取り違えやすい。推定量 \\(\varepsilon = \\|y_5 - y_4\\|\\) は
**4次解の**局所誤差なので \\(O(h^5)\\) であり、5次解の局所誤差 \\(O(h^6)\\) は測れていない。
1ステップ分の誤差を \\(h\\) を半分にしながら測ると、差 \\(\\|y_5-y_4\\|\\) の落ち方と
5次解の真の誤差の落ち方は、次数がひとつ違う形で分かれる。

Hairer の `dopri5` も scipy の `RK45` も `expo1 = 0.2`、すなわち \\(1/5\\) を使っている。
**ステップを棄却して \\(h\\) を縮めて再試行する**分岐が要る点が、
制御の実装を面倒にする。

## 陰的解法と安定性

### stiff とは何か

解の中に時間スケールの大きく違う成分が共存する問題を stiff という。
速い成分がとうに減衰して解に寄与していなくても、**陽解法はその速い成分の
時間スケールで刻まないと爆発する。**

つまり刻み幅を縛っているのが精度ではなく安定性である。ここが stiff の定義的な特徴で、
「必要な精度に対して不必要に細かい刻みを強制される」状態を指す。

### A-安定性

試験方程式 \\(y' = \lambda y\\)（\\(\mathrm{Re}\,\lambda < 0\\)、真の解は減衰）に解法を当てると、
\\(y_{n+1} = R(h\lambda) y_n\\) の形になる。\\(R\\) を**安定性関数**という。
数値解が減衰する条件は \\(|R(z)| \le 1\\) で、これを満たす \\(z = h\lambda\\) の集合が**安定領域**。

- Euler 陽解法: \\(R(z) = 1+z\\)。安定領域は \\(|1+z|\le 1\\)、
  複素平面上の中心 \\(-1\\) 半径 1 の円の内部だけ
- RK4: \\(R\\) は4次多項式。領域は広がるが、やはり有界（実軸上の端は \\(-3\\) 手前）

**陽的 Runge–Kutta の \\(R\\) は多項式である。** 多項式は \\(|z|\to\infty\\) で必ず発散するから、
**安定領域は必ず有界**になる。したがって

> 陽的 Runge–Kutta は原理的に A-安定になれない。

A-安定とは「左半平面全体が安定領域に含まれる」こと。これは実装の巧拙ではなく
**構造的な不可能性**である。

一方、後退 Euler は \\(R(z) = 1/(1-z)\\)、台形則は \\(R(z) = (1+z/2)/(1-z/2)\\) で、
どちらも有理関数。左半平面全体で \\(|R|\le 1\\) となり **A-安定**である。

### A-安定では足りない——L-安定性

A-安定は \\(|R| \le 1\\) しか要求しない。stiff 問題で実際に効くのは
\\(z \to -\infty\\) で \\(|R|\\) がどうなるかである。

| 手法 | \\(R(z)\\) | \\(z\to-\infty\\) |
|---|---|---|
| 後退 Euler | \\(1/(1-z)\\) | \\(\to 0\\) |
| 台形則 | \\((1+z/2)/(1-z/2)\\) | \\(\to -1\\) |

**A-安定かつ \\(R(z)\to 0\ (z\to-\infty)\\)** を L-安定という。後退 Euler は L-安定、台形則はそうでない。

台形則は速い成分を減衰させず、符号を反転させながら保持する。
\\(y' = -1000y\\) を台形則で \\(h=0.1\\) として解くと \\(R\\) は \\(-1\\) のわずかに内側で、
\\(|R| < 1\\) だから「安定」だが、\\(t=1\\) まで進めても \\(|y|\\) はほとんど落ちない（真値はほぼ 0）。

つまり**「A-安定だから stiff に使える」は成り立たない。** 後述の完了条件で
陰解法を試すときは後退 Euler を使うこと。台形則を選ぶとこの符号振動で混乱する。

### Dahlquist の第2障壁

線形多段法では、

> **A-安定な線形多段法の次数は2以下。** さらに、2次で誤差定数が最小なのは台形則。

高次と A-安定性は両立しない。stiff 問題で高次が欲しければ、
多段法ではなく陰的 Runge–Kutta へ行くことになる。

### 陰的解法は章1を呼ぶ

後退 Euler は

\\[
y_{n+1} = y_n + h f(t_{n+1}, y_{n+1})
\\]

で、**\\(y_{n+1}\\) が両辺に出る。** \\(f\\) が非線形なら、各ステップで非線形方程式を解く必要がある。

**ここで章1の Newton 法を再利用する。** そしてスカラーでなく系なら、
Newton の内側で線形方程式を解く——**章2である。**

章4は既に書いた2章に依存する。モジュール境界の設計が問われるのはここで、
章1の `newton` が「スカラーの `f64` を返す」形に固まっていると、
系に対して使えず書き直しになる。章1でどう受け取る形を選んだかが、ここで評価される。

## Rust の言語機構

### 状態の型に対する generic——必要な演算だけを要求する

スカラーの ODE も連立 ODE も同じコードで扱いたい。RK4 が状態 \\(y\\) に要求する演算は

\\[
y + h k, \qquad k_1 + 2k_2 + 2k_3 + k_4, \qquad \frac{h}{6}k
\\]

——加算とスカラー倍だけである。つまり**ベクトル空間であれば足りる。**

選択肢が4つある。

| 形 | 得るもの / 失うもの |
|---|---|
| `Vec<f64>` | 実行時に次元が決まる。毎ステップ確保が起きうる |
| `[f64; N]`（const generics） | 確保なし、スタック上。次元がコンパイル時に決まる必要がある |
| `nalgebra::SVector<f64, N>` | 演算子が最初から揃っている。クレート依存が入る |
| 独自トレイト | 上の全部を受けられる。トレイト境界を自分で書く |

最後の形が、**「必要な演算だけをトレイトで要求する」**という Rust の設計が
最も綺麗に効く例である。境界としては `Add<Output=Self> + Mul<f64, Output=Self> + Clone`
あたりで足りるはずで、**足りるかどうかは RK4 を書いてみると分かる。**

注意点が一つある。`Vec<f64>` を状態にすると、`y + h*k` のたびに新しい `Vec` が確保される。
毎ステップ数回の確保が入り、これが支配的になりうる。
**確保を避ける形（`&mut` に書き込む in-place な演算）にすると、
トレイト境界が `Add` では書けなくなる。** 抽象の綺麗さと確保の回数が正面から衝突する場所で、
どちらを取るかは測ってから決めるとよい。

### 右辺 \\(f(t,y)\\) をどう受けるか

章1と同じ問いだが、条件が増える。**パラメータ付きの右辺**（減衰係数、外力の振幅）を
どう持つか。クロージャに捕獲させるか、トレイトの実装型のフィールドに持つか。
後者は「同じ方程式をパラメータを変えて何度も解く」形に向く。

### 出力をどう返すか

適応刻みの結果は不定長である。

- `Vec<(f64, Y)>` に貯める——単純。全部メモリに乗る
- `Iterator<Item = (f64, Y)>` として遅延生成する——**Rust らしい。**
  途中で止められる、無限に流せる、`take_while` で条件を書ける

**後者は刻み幅制御と組み合わせると設計が難しい。** ステップの棄却（誤差が大きすぎて
やり直す）を `Iterator::next` の中でどう表現するか、
状態（現在の \\(h\\)、直前の誤差）をどこに持つか。
`next` が「1回の成功したステップ」を返すのか「1回の試行」を返すのかで意味が変わる。

`Iterator` は失敗を表現しにくい（`Item = Result<...>` にすると使う側が煩雑になる）ことも
併せて考える必要がある。

## オラクル

解析解を持つ系を使う。

| 系 | 解析解 |
|---|---|
| \\(y' = \lambda y,\ y(0)=1\\) | \\(y = e^{\lambda t}\\)。\\(\lambda\\) を負の大きい値にすると stiff の実験になる |
| 調和振動子 \\(y'' = -\omega^2 y\\) | \\(y = A\cos(\omega t + \phi)\\)。エネルギー \\(\frac12(y'^2 + \omega^2y^2)\\) が保存するので、誤差をエネルギーで測れる |
| \\(y' = -2ty^2,\ y(0)=1\\) | \\(y = 1/(1+t^2)\\) |
| Van der Pol | 解析解なし。高精度の参照解を自分で作る（十分小さい刻みの RK4） |

SDE のオラクルは章4bに置いた。

## 完了条件

### 1. ODE の収束次数

Euler 1次、RK4 4次。\\(y' = -y,\ y(0)=1,\ T=1\\) で測る。

RK4 は測る \\(h\\) の範囲を選ばないと測れない。\\(h\\) を小さくしていくと誤差はいずれ
丸め誤差の床で下げ止まり、そこから先は傾きが崩れて最後は負になる。

**RK4 は丸めの床に当たる前の \\(h\\) で測ること。** 判定は**小数1桁まで 4.0 が出ること**とする。

Euler にはこの罠がない——刻みをどれだけ細かくしても傾きは 1.0 のまま安定している
（丸めの蓄積が打ち切り誤差より小さいままだから）。
**この非対称性そのものを観察対象にするとよい。**

### 2. stiff で陽解法が破綻し陰解法が通る

\\(y' = -1000y\\) で、陽的 Euler は \\(h > 2/1000\\) で発散する。境界はきっかりしている:
\\(h = 2/1000\\) ちょうどでは \\(R = -1\\) で減衰も発散もせず、そこからわずかに大きくすると
\\(|y|\\) は増え始め、少し離すだけで桁で膨らむ。

\\(R\\) が負なので **\\(y\\) の符号はステップ数の偶奇で反転する**（値は \\(|y|\\) で見る）。
「発散するかしないか」の二値ではなく、\\(|R|=1\\) の境界で振動が持続する状態を挟む。

陰解法側は**後退 Euler を使うこと。** \\(R = 1/(1+1000h) \in (0,1)\\) でどの \\(h\\) でも減衰する。
台形則を選ぶと前述の L-安定性の問題で符号振動が出る。
