# FFT と Monte Carlo

一見無関係な話題を同じ章に置く。共通するのは**「収束の速さが何で決まるか」が
これまでの章と違う原理で決まる**点である。FFT は計算量の話、
Monte Carlo は**次元に依らない**収束の話で、どちらも章3の \\(O(h^p)\\) の枠の外にある。

## 離散 Fourier 変換

\\[
X_k = \sum_{n=0}^{N-1} x_n\, e^{-2\pi i kn/N}, \qquad k = 0,\ldots,N-1
\\]

素朴に計算すると \\(N\\) 個の \\(X_k\\) それぞれに \\(N\\) 回の積和で \\(O(N^2)\\)。

### Cooley–Tukey

\\(N\\) が偶数のとき、和を偶数番目と奇数番目に割る。
\\(W_N = e^{-2\pi i/N}\\) と置くと

\\[
X_k = \underbrace{\sum_{m} x_{2m} W_{N/2}^{km}}\_{E_k} + W_N^k \underbrace{\sum_{m} x_{2m+1} W_{N/2}^{km}}\_{O_k}
\\]

\\(E_k, O_k\\) は長さ \\(N/2\\) の DFT そのものである。ここから2つの事実を使う——
\\(W_N^{k+N/2} = -W_N^k\\)（回転因子の反周期性）と、
**\\(E_{k+N/2} = E_k\\)、\\(O_{k+N/2} = O_k\\)**（長さ \\(N/2\\) の DFT なので \\(k\\) について \\(N/2\\) 周期）。
後者を落とすと後半の式が出ない。

\\[
X_k = E_k + W_N^k O_k, \qquad X_{k+N/2} = E_k - W_N^k O_k
\\]

前半と後半が同じ2つの量から出る。 \\(E_k, O_k\\) を \\(k < N/2\\) について計算すれば
\\(X\\) が全部埋まる。再帰の深さ \\(\log_2 N\\)、各段で \\(O(N)\\) なので \\(O(N\log N)\\)。

\\(W_N^k\\) を回転因子（twiddle factor）という。事前計算して表に持つのが普通で、
これが `rustfft` のプランが存在する理由の一つである。

### bit-reversal permutation

再帰版は素直だが、確保と関数呼び出しが多い。反復版（in-place）にすると、
最初に入力を bit 反転の順に並べ替える必要がある。

偶数/奇数で分けていく操作は、添字の最下位ビットで分ける操作である。
これを \\(\log_2 N\\) 段繰り返すと、最終的な位置は元の添字のビットを逆順にしたものになる。
並べ替えた後は、隣接する要素対にバタフライ演算を当てるだけで、
段を追うごとに距離が倍になる。

### 2の冪でない長さ

Cooley–Tukey は \\(N\\) が合成数なら使える（mixed-radix）。
\\(N\\) が素数だと分割できないので、Bluestein のアルゴリズムで
DFT を畳み込みに書き換え、ゼロ詰めして2の冪の FFT に帰着させる。

実用のライブラリはこれらを組み合わせて任意長を扱う。
自作は2の冪だけに限るのが妥当で、そこから先はライブラリの仕事である。

## Monte Carlo 積分

\\[
\int_{[0,1]^d} f(x)\,dx \approx \frac1N \sum_{i=1}^{N} f(x_i), \qquad x_i \sim U([0,1]^d)
\\]

推定量の分散は \\(\mathrm{Var}(f)/N\\) なので、標準誤差は

\\[
\frac{\sigma(f)}{\sqrt N} = O(N^{-1/2})
\\]

これが成り立つには \\(\sigma^2(f) < \infty\\) が要る。そして
**「\\(d\\) に依らない」のは収束の次数であって、定数 \\(\sigma(f)\\) ではない。**
\\(\sigma\\) が \\(d\\) とともに指数的に増える被積分関数はいくらでもある——
後述の \\(\prod(1+(x_i-\tfrac12))\\) がそれで、\\(\sigma = \sqrt{(13/12)^d-1}\\)。
ただし増え方は緩く、この章で扱う次元では定数はまだ効かない——
「定数が巨大で実用にならない」が実際に起きるのはずっと高い次元である。

\\(\prod x_i\\) は逆の形で困る。\\(\sigma = \sqrt{3^{-d}-4^{-d}}\\) は指数的に**減る**が、
真値 \\(2^{-d}\\) はもっと速く減るので**相対**標準偏差が爆発する。

もう一点、\\(\sigma/\sqrt N\\) は RMSE（あるいは中心極限定理による確率的な区間）であって、
**決定論的な上界ではない。** 後述の Koksma–Hlawka と並べるときはこの違いが効く。

一方、章3の決定論的な求積を \\(d\\) 次元へテンソル積で拡張すると、
\\(N\\) 点で1次元あたり \\(N^{1/d}\\) 点しか置けず、誤差は \\(O(N^{-p/d})\\) になる——
**次元の呪い**である。ただしこちらにも仮定があり、Simpson の \\(p=4\\) は \\(f \in C^4\\) を要求する。

したがって交差点がある。\\(N^{-p/d}\\) と \\(N^{-1/2}\\) を比べて、

\\[
d > 2p \quad\Longrightarrow\quad \text{Monte Carlo が勝つ}
\\]

Simpson（\\(p=4\\)）なら \\(d > 8\\) あたり。**高次元で MC が使われるのはこれだけが理由である。**
逆に低次元では MC は遅い——1次元の積分に MC を使う理由はない。

\\(O(N^{-1/2})\\) は遅い。桁を1つ稼ぐのに \\(N\\) を100倍する。
だから分散削減が要る。

### 分散削減

- 対称変量（antithetic variates）: \\(x\\) と \\(1-x\\) を対にする。
  \\(f\\) が単調なら負の相関が生まれて分散が減る
- 制御変量（control variates）: 期待値の分かっている \\(g\\) を使い、
  \\(f - c(g - \mathbb{E}g)\\) を推定する。最適な \\(c\\) は \\(\mathrm{Cov}(f,g)/\mathrm{Var}(g)\\)
- 重点サンプリング: \\(f\\) が大きい領域を密にサンプルし、
  密度比で補正する。\\(\int f = \int (f/p)\,p\\)。\\(p\\) の選び方が悪いと分散が増える
  （分散が無限大になることさえある）

いずれも推定量を不偏に保ったまま分散だけ下げるのが要点である。

## 準乱数——「ランダムでないほうが速い」

Sobol 列や Halton 列は、乱数ではなく一様に散らばるよう決定論的に構成された点列である。
「どれくらい一様か」を測る量が**星型判別数 \\(D_N^\*\\)** で、
**原点にアンカーされた**軸平行な箱 \\([0,b_1)\times\cdots\times[0,b_d)\\) すべてについて、
「箱に入った点の割合」と「箱の体積」の差の上限として定義される。
アンカーを外して任意の軸平行な箱にしたものは extreme discrepancy \\(D_N\\) と呼ばれる別の量で、
\\(D_N^\* \le D_N \le 2^d D_N^\*\\) で結ばれるだけで一致しない。
以下の不等式は \\(D_N^\*\\) 版である。

**Koksma–Hlawka の不等式**が誤差を判別数で押さえる。

\\[
\left| \frac1N\sum_{i=1}^N f(x_i) - \int_{[0,1]^d} f \right| \le V(f)\, D_N^\*
\\]

\\(V(f)\\) は Hardy–Krause の意味での関数の変動。\\(d=1\\) なら全変動、
\\(d \ge 2\\) では座標の部分集合ごとの偏変動の和である。右辺が
関数の性質と点列の性質の積に完全に分離しているのが美しい点で、
点列だけを良くすれば誤差が下がる。

低食い違い列は \\(D_N^\* = O((\log N)^d / N)\\) を達成する。したがって

\\[
\text{誤差} = O\left(\frac{(\log N)^d}{N}\right)
\\]

低次元では \\(N^{-1/2}\\) より \\(N^{-1}\\) に近い。「ランダムでないほうが速い」ことに
明確な数学的理由がある。金融の Monte Carlo では標準的に使われる。

### ただし Koksma–Hlawka は高次元では何も言っていない

\\((\log N)^d/N\\) が \\(N^{-1/2}\\) を下回る \\(N\\)、
そもそも 1 を下回る \\(N\\)——どちらも \\(d\\) について**二重指数的に**増える。
自分で \\(d\log\log N = \log N\\) を解いてみるとよい。

**この章の実験の \\(N\\) では、\\(d\\) が少し上がるだけで上界が 1 を超える**——
「誤差は 1 以下」より弱い、自明な主張になっている。
それでも実測では、かなり高い次元でも QMC が勝つことがある。
つまり **\\((\log N)^d\\) は観測される挙動の説明になっていない。**
Koksma–Hlawka は**上界であって収束率ではない。** 漸近的には有効だが、
上界が意味を持ち始める \\(N\\) が \\(d\\) とともに爆発するので、
**\\(d\\) が少し大きくなるだけで事実上到達不能になる。**

### 勝敗を決めるのは実効次元

実際に効くのは名目の次元 \\(d\\) ではなく**実効次元（effective dimension）**——
ANOVA 分解で、分散のうち低次の項がどれだけを占めるかである。
低次項が支配していれば、Halton や Sobol の低次元射影が良いという性質が効く。

実効次元でグレード分けした関数を比べると、傾向がはっきり分かれる。

- **加法的な \\(\sum x_i\\)**（実効次元 1）は、\\(d\\) を上げても QMC が優位を保ちやすい
- **全座標が等しく寄与する \\(\prod(1+(x_i-\tfrac12))\\)** は、\\(d\\) が数十で逆転する
- **不連続な \\(1[\sum x_i \le d/2]\\)** は \\(V(f)=\infty\\) で、Koksma–Hlawka の保証自体が効かない

**「常に QMC が勝つ」でも「\\(d\\) が大きいと必ず負ける」でもない。**

### 測っているものが2つ混ざる

ここが QMC の実験で最も間違えやすい点である。素の Halton 列で比べると、
**実効次元の効果と、列そのものの欠陥が混ざる。** Halton は高次元の座標で基数が大きくなり、
\\(N\\) が小さいうちは高次元射影が悪い。これは理論とは無関係な要因で、
**ランダムシフト（Cranley–Patterson）を掛けて RMSE を取ると大きく緩和する。**

実際、素の列で「逆転した」ように見えた次元でも、シフトを入れると拮抗まで戻ることがある。
**どちらを測っているのかを切り分けないと、理論の検証にならない。**

もう一つ、比べる相手の定義を先に決めること。MC 側の誤差を
\\(\sigma(f)/\sqrt N\\) の解析値で置くか、\\(R\\) 反復の経験 RMSE で置くかで数字が変わる。
どちらでもよいが、**混ぜると同じ実験の結論が反転する。**

## Rust の言語機構

### `Complex<f64>` か、実部と虚部を分けるか

`num-complex` の `Complex<f64>` は 2 つの `f64` を持つ構造体で、
`Vec<Complex<f64>>` は `[re, im, re, im, ...]` と交互に並ぶ（AoS）。

対して実部の配列と虚部の配列を別に持つ（SoA）と、
**同じ種類の値が連続に並ぶ。**

| | AoS `Vec<Complex<f64>>` | SoA `(Vec<f64>, Vec<f64>)` |
|---|---|---|
| コードの読みやすさ | 演算子が使えて素直 | 実部・虚部を手で書く |
| SIMD | ベクトル化しにくい | **連続する 4 つの実部を1命令で扱える** |
| キャッシュ | 実部だけ欲しいときも虚部を読む | 必要な側だけ読む |

**SIMD 化を考えるなら SoA** という、データレイアウトの古典的なトレードオフである。
これは Rust 固有の話ではないが、**Rust では型として明示的に選ぶ**ことになる
（暗黙のレイアウト変換がない）。

### 再帰版と反復版、in-place にできるか

再帰版は「偶数番目を集めた `Vec` と奇数番目を集めた `Vec` を作る」形になり、
段ごとに確保が起きる。反復版は bit-reversal で並べ替えた後、
同じ配列の中でバタフライを回すので追加確保がゼロにできる。

in-place のバタフライは「配列の 2 箇所を同時に可変で触る」操作なので、
**章2の `split_at_mut` と同じ問題が出る。** 距離が段ごとに変わるので、
分割の仕方も段ごとに変わる。

### プランを持つ API

`rustfft` は `FftPlanner` から `Fft` を作り、それを使い回す設計になっている。
理由は**回転因子とビット反転表の事前計算**で、
同じ長さの変換を繰り返すなら1回で済む。

**章3で「積分器を返す形」を考えたのと同じ構造**である。
前計算を型に載せて、使い回せる単位として渡す。

### 乱数をどう注入するか

**グローバルな乱数状態を使わない。** `rand` の `thread_rng()` は手軽だが、
再現性が無く、テストが不安定になる。

シードを引数で受けて、そこから決定論的に RNG を作る形にする。

問いが残る。**RNG をどう渡すか**——`&mut impl Rng` を各関数に引き回すか、
サンプラーが RNG を所有するか。前者は関数のシグネチャが汚れるが、
呼び出し側が RNG の種類を選べる。後者は綺麗だが、
**`&mut R` を持つと借用が伝播する**（サンプラーが `Iterator` を返せなくなる、など）。

章4bの SDE でも同じ問題が出るので、**両方で使える形にしておきたい。**

## オラクル

### FFT

- 往復テスト（`proptest`）: `ifft(fft(x)) == x` を機械精度で。
  正解を用意せずに広い入力を叩ける、性質テストの理想形である
- `rustfft` との相互検証: 同じ入力で機械精度まで一致させる。
  章0の FMA の注意——**`mul_add` を使うと bit 単位では一致しない**ので、
  許容は「機械精度のオーダー」であって「厳密一致」ではない
- 解析的に分かる変換: 単位インパルス \\(\delta_0\\) の DFT は全 1、
  定数列の DFT は \\(k=0\\) だけに集中、単一周波数の正弦波は
  対応する \\(k\\) と \\(N-k\\) だけに立つ
- Parseval の等式: \\(\sum|x_n|^2 = \frac1N\sum|X_k|^2\\)。
  これも不変量として使える

### Monte Carlo

実効次元でグレード分けした3本を使う。これは意図的な選び方である——
1本目は QMC が勝ち続ける側、3本目は逆転する側の対照になる。

| 積分 | 値 | 実効次元 | \\(\sigma\\) |
|---|---|---|---|
| \\(\int_{[0,1]^d} \sum x_i\,dx\\) | \\(d/2\\) | 1（加法的） | \\(\sqrt{d/12}\\) |
| \\(\int_{[0,1]^d} \prod\left(1 + (x_i - \tfrac12)\right)dx\\) | \\(1\\) | \\(d\\)（等寄与） | \\(d\\) とともに増える |
| \\(\int_{[0,1]^d} 1\\!\left[\sum x_i \le \tfrac d2\right]dx\\) | \\(1/2\\)（対称性から厳密） | 中間 | \\(1/2\\)（\\(d\\) に依らない） |

3本目は \\(\sigma\\) が \\(d\\) に依らないので比較が公平で、しかも \\(V(f) = \infty\\)
（不連続）の実例にもなっている。

次のものは使えない。

- \\(\int \prod x_i\,dx = 2^{-d}\\) は相対標準偏差 \\(\sqrt{3^{-d}-4^{-d}}/2^{-d}\\) が
  \\(d\\) とともに爆発し、\\(d\\) が数十では MC も QMC も相対で数割の誤差になる。
  絶対誤差で比べると「両方だめ」を「互角」と読んでしまう
- **単位球の体積（棄却法）は交差を見たい次元の直前で死ぬ。** 採択確率 \\(V_d/2^d\\) が
  \\(d\\) とともに指数的に落ちるので、交差を見たい次元に届く前にヒットが枯れる

## 完了条件

### 1. FFT

- **自作 FFT が `rustfft` と機械精度で一致**
- **往復テスト（IFFT∘FFT = 恒等）を `proptest` で**

### 2. MC と QMC の優劣の逆転

手順を指定しないと測れないので、明示する。

- \\(N = 2^8, \ldots, 2^{16}\\)
- **MC 側の誤差の定義を先に決めて、最後まで変えない**（\\(\sigma/\sqrt N\\) か経験 RMSE か）
- **MC を経験 RMSE で測るなら反復を数十回取る。** 単一走行の誤差曲線はランダムウォークで、
  \\(-1/2\\) の直線には見えない——seed によっては傾きが正になることすらある。
  数十回の RMSE なら \\(-0.5\\) の近くに落ち着く
- **QMC は素の Halton とランダムシフトの両方で測る。**
  片方だけでは、実効次元の効果と列の欠陥のどちらを見ているか分からない
- シフト付きの RMSE は反復が少ないと大きく振れる。判定に使うなら反復をさらに多く取る

**\\((\log N)^d\\) は逆転の説明になっていない。** 加法的な関数を対照として一緒に測ると、
名目の次元では説明がつかないことがはっきりする。

### 3. 決定論的求積との交差（縮小版）

テンソル積の合成 Simpson は \\((2m+1)^d\\) 点かかるので、**交差点の実測は事実上不可能である。**
次数を最小二乗で当てるには複数の水準が要るが、\\(d=10\\) で \\(10^9\\)、
\\(d=12\\) で \\(10^{11}\\) のオーダーの評価になる。交差は \\(d>8\\) に住むので、正面からは届かない。

現実的な形はこうなる。

- \\(d = 4, 6, 8, 10\\) で次数だけ測り、**外挿で交差を確認する**
- 決定論側を台形則（\\(p=2\\)、交差は \\(d>4\\)）にする。\\(d=5,6,7\\) なら
  \\(10^6\\) 台の評価回数で収まる

Simpson を選んだ結果として実験が不可能になる、というのがここの教訓である。
