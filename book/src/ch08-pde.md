# 偏微分方程式——差分法

終着点の前半。ここでは差分法だけを扱う。数値解析としての中身が濃いのはこちらで、
**「安定」という語がまた別の意味になる**のがこの章である
（章0の「安定な式」、章2の後退安定性、章4の A-安定性とは別概念で、名前が同じだけである。
記号表に対照表がある）。

Rust の設計緊張が最大になるのは後半の章8b（有限要素法）のほうで、
そちらは疎行列・メッシュ・並列アセンブリ・matrix-free を扱う。

## 差分法

### 熱方程式と安定性

\\[
u_t = \alpha u_{xx}
\\]

空間を2階中心差分、時間を前進差分で離散化する（陽解法）と

\\[
u_j^{n+1} = u_j^n + r\left(u_{j+1}^n - 2u_j^n + u_{j-1}^n\right), \qquad r = \frac{\alpha\,\Delta t}{\Delta x^2}
\\]

これは \\(r\\) が大きいと発散する。精度の問題ではなく、
誤差が指数的に増幅される。

### von Neumann 安定性解析

スキームが**線形・定数係数で、境界が周期的（または領域が無限）**なら、
誤差を Fourier モードに分解して各モードの増幅率を見ればよい。
\\(e^{ikj\Delta x}\\) が離散作用素の固有関数になるのはこの条件の下だけである。
\\(u_j^n = g^n e^{ikj\Delta x}\\) を代入する。

\\[
g = 1 + r\left(e^{ik\Delta x} - 2 + e^{-ik\Delta x}\right) = 1 + 2r(\cos k\Delta x - 1) = 1 - 4r\sin^2\frac{k\Delta x}{2}
\\]

増幅率 \\(g(k)\\) が、1ステップでそのモードが何倍になるかである。
全モードで \\(|g| \le 1\\) を要求する。\\(\sin^2\\) は最大 1 なので最悪は \\(g = 1-4r\\)、

\\[
|1 - 4r| \le 1 \quad\Longleftrightarrow\quad \boxed{r \le \tfrac12}
\\]

\\(\Delta t \le \Delta x^2/(2\alpha)\\)。**時間刻みが空間刻みの二乗で縛られる。**
空間を2倍細かくすると時間刻みは4分の1になり、計算量は8倍になる。
**これが陰解法を使う動機である。**

破れ方も予測できる。\\(r > 1/2\\) では \\(|g| > 1\\) となるモードが
最も高い波数（格子間隔で振動するモード）から現れる。
だから発散は「一つおきに符号が反転する鋸歯」として現れ、
**滑らかな誤差の増大としては現れない。** 実測でこの形が見えたら von Neumann の予測どおりである。

### Dirichlet では閾値が少しずれる

この章が実際に扱うのは Dirichlet 問題で、周期境界ではない。そこでは固有ベクトルが
\\(\sin(m\pi j\Delta x)\\)、波数が \\(k\Delta x = m\pi/N\\)（\\(m = 1,\ldots,N-1\\)）という
離散集合に限られ、\\(k\Delta x = \pi\\) はそもそも取れない。したがって厳密な閾値は
\\(\max_m |1 - 4r\sin^2(m\pi/2N)| \le 1\\) から

\\[
r \le \frac{1}{2\cos^2(\pi/2N)}
\\]

| \\(N\\) | 厳密な \\(r_{\text{crit}}\\) |
|---|---|
| 4 | 0.5858 |
| 8 | 0.5198 |
| 20 | 0.5031 |
| 64 | 0.5003 |

\\(r \le 1/2\\) は \\(\Delta x \to 0\\) の極限条件であって、有限の \\(N\\) での厳密な閾値ではない。
後の完了条件でここが効く——\\(N=20\\) で \\(r = 0.502\\) にしても発散しない。

もう2つ、通常は省略される条件がある。\\(|g| \le 1\\) は真の解が増大しない問題に対する形で、
一般には \\(|g| \le 1 + C\Delta t\\) でよい。そして連立系では固有値の \\(|g|\le1\\) は
必要条件にすぎない（増幅行列が正規でないと十分でなく、Kreiss の行列定理が要る）。
本章は単一方程式しか扱わないので後者は出てこない。

### 用語の注意——von Neumann と Neumann は別人

- **von Neumann 安定性解析** — John von Neumann
- **Neumann 境界条件**（\\(\partial u/\partial n\\) を与える） — Carl Neumann

**別人である。** この章では両方が同時に出てくるので混ざりやすい。

### CFL 条件

波動方程式 \\(u_{tt} = c^2 u_{xx}\\) の陽解法では

\\[
\frac{c\,\Delta t}{\Delta x} \le 1
\\]

これが **Courant–Friedrichs–Lewy 条件**（\\(\nu = c\Delta t/\Delta x\\) を Courant 数という）。
対象のスキームは leapfrog

\\[
u_j^{n+1} = 2u_j^n - u_j^{n-1} + \nu^2\left(u_{j+1}^n - 2u_j^n + u_{j-1}^n\right)
\\]

である。意味は明快で、
**数値スキームの依存領域が、真の解の依存領域を含んでいなければならない。**
1ステップで情報が \\(\Delta x\\) しか伝わらないのに、物理が \\(c\Delta t > \Delta x\\) 伝わるなら、
必要な情報が数値解に届いていない。

CFL は一般には**必要条件であって十分条件ではない。** このスキームでは
von Neumann 解析から必要十分になるが、それはこのスキームの性質である。

\\(u^{n-1}\\) を参照するので**第1ステップを別に与える**必要がある。\\(u_t = 0\\) なら対称性から

\\[
u^1_j = u^0_j + \tfrac{\nu^2}{2}\left(u^0_{j+1} - 2u^0_j + u^0_{j-1}\right)
\\]

が2次精度の始動である。\\(u^1 = u^0\\) で済ませると精度が落ちるだけでなく、
下の境界ケースの挙動そのものが変わる。

そして熱方程式と同じく、Dirichlet では閾値がずれる。厳密には \\(\nu < 1/\cos(\pi/2N)\\) で、
**等号が入らない**——等号では最高波数モードで増幅行列が重根 \\(g=-1\\) を持って欠損するので、
一般化固有ベクトル成分を含む初期データに対して \\(n\\) に比例して増大する
（単一モードちょうどだとその成分が出ないので有界に見える。それでも一様有界性は破れている）。
熱方程式の \\(r \le 1/(2\cos^2(\pi/2N))\\) は単根なので等号込みでよい。

**\\(\\|u\\|_\infty\\) のスナップショットを安定性の判定に使わないこと。** これは位相の値なので、
ステップ数を1つずらすだけで大きく変わる（\\(\nu=1\\) では厳密に周期的で、
周期の倍数のステップでちょうど初期値に戻る）。判定には熱方程式側と同じく
**鋸歯初期条件＋増幅率の幾何平均**を使う。

閾値を明確に超えれば発散するが、初期条件が滑らかなモードだと
不安定モードが丸め誤差でしか励起されないため、到達する値は実装依存になる。

熱方程式の \\(\Delta t \sim \Delta x^2\\) と波動方程式の \\(\Delta t \sim \Delta x\\) の違いは、
**放物型と双曲型の違い**（伝播速度が無限か有限か）に対応している。

### Lax の同値定理

> 適切に設定された線形初期値問題に対し、適合性を持つ**線形**差分スキームについて
> **安定性 \\(\Longleftrightarrow\\) 収束性**

「線形」は問題だけでなく**スキームにも掛かる。** 非線形スキームには適用できない。
そして安定性も収束性も**ノルムを固定して初めて意味を持つ**——
Lax の言う安定性は「差分作用素のべき \\(C^n\\) が \\(0 < n\Delta t \le T\\) で一様有界」で、
これが von Neumann の \\(|g| \le 1\\) と同じものになるのは \\(l^2\\) ノルムを取ったときである
（章7の Parseval の等式を経由する）。

適合性（consistency）は「\\(\Delta t, \Delta x \to 0\\) で差分方程式が元の PDE に近づく」ことで、
Taylor 展開で確かめられる。収束性は「数値解が真の解に近づく」こと。

要点は、**適合性だけでは収束が保証されない**ことである
（適合かつ不安定なスキームが特定の初期条件で収束することはある。保証が無いだけである）。
「離散化が正しい」と「安定」は独立で、両方要る。
そして収束性を直接示すのは難しいが、適合性と安定性は個別に確かめやすい——
**だからこの定理が実用的な価値を持つ。**

### 線の方法

空間だけ離散化して、時間については連立 ODE

\\[
\frac{d\mathbf{u}}{dt} = A\mathbf{u}
\\]

と見る。そのまま章4のソルバーに渡せる。

そして \\(A\\)（2階中心差分の行列）の固有値は \\(-4\alpha/\Delta x^2 \cdot \sin^2(\cdot)\\) の形で、
**最大と最小の比が \\(\Delta x^{-2}\\) のオーダーになる。**
つまり**熱方程式は定義から stiff である。** 章4で陰解法を書いた理由がここで回収される。

線の方法で陽的 Euler を使うと、\\(R(z) = 1+z\\) に
\\(\lambda_m = -(4\alpha/\Delta x^2)\sin^2(m\pi\Delta x/2)\\) を入れて
\\(|1 - 4r\sin^2(m\pi\Delta x/2)| \le 1\\) となり、von Neumann の \\(g\\) と**同じ式**が出る。

ここで**「A-安定性」と言ってはいけない。** 陽的 Euler は A-安定ではない——
章4で見たとおり、陽的 Runge–Kutta は原理的に A-安定になれない。
一致するのは**絶対安定領域（region of absolute stability）**のほうである。

章2で「章4の A-安定性と章8の von Neumann 安定性は名前が同じだけの別概念」と書いた。
それは正しい。ここで起きているのは、**線の方法を経由するとこの場合に限って
同じ式から出る**ということであって、2つが同じ概念だという意味ではない。

### 陰解法——Crank–Nicolson

\\(r \le 1/2\\) の制約を外すには時間方向を陰的にする。時間について台形則を取ると
Crank–Nicolson で、増幅率は

\\[
g = \frac{1 - 2r\sin^2(k\Delta x/2)}{1 + 2r\sin^2(k\Delta x/2)}
\\]

分子の絶対値が分母以下なので、**すべての \\(r > 0\\) で \\(|g| \le 1\\)**——無条件安定である。
von Neumann の枠内で1行で示せる。

ただし章4の L-安定性の話がここにも効く。\\(r \to \infty\\) で \\(g \to -1\\) なので、
Crank–Nicolson は高波数モードを減衰させず符号反転させながら保持する。
初期条件が不連続だと、その振動が長く残る。減衰させたいなら後退 Euler（1次だが L-安定）を使う。

## オラクル

### 熱方程式

\\(u_t = u_{xx}\\)、\\(u(0,t)=u(1,t)=0\\)、\\(u(x,0)=\sin(m\pi x)\\) の解は

\\[
u(x,t) = e^{-m^2\pi^2 t}\sin(m\pi x)
\\]

単一の Fourier モードは形を保って指数的に減衰するだけなので、
数値解の減衰率を理論値と直接比べられる。
von Neumann 解析が扱っているのもまさにこのモードなので、
増幅率 \\(g\\) の予測と実測を1対1で対応させられる。
ただし**そのために \\(r>1/2\\) の発散実験には使えない**（完了条件を参照）。

一般の初期条件は Fourier 級数で書ける。

### 波動方程式

全空間の \\(u_{tt} = c^2u_{xx}\\) は d'Alembert の解 \\(u = F(x-ct) + G(x+ct)\\) を持ち、
初期条件 \\(u(x,0)=\varphi(x)\\)、\\(u_t(x,0)=\psi(x)\\) から

\\[
u(x,t) = \tfrac12\left(\varphi(x-ct) + \varphi(x+ct)\right) + \frac{1}{2c}\int_{x-ct}^{x+ct}\psi(s)\,ds
\\]

と決まる。Dirichlet 境界のある区間で使うには奇関数拡張して周期化する。
照合を簡単にしたいなら、**熱方程式と同じくモード解**を使うのが楽である——
\\(u(x,0) = \sin(m\pi x)\\)、\\(u_t(x,0)=0\\) なら \\(u = \cos(m\pi ct)\sin(m\pi x)\\)。
CFL の破れ方を見るのは前述の leapfrog で、比べる値がこれになる。

## この章で決めること

1. 格子を1本の `Vec<f64>` で持つか、時間方向の層を複数持つか
2. 境界条件をどう課すか（配列の端を固定するか、内部自由度だけを持つか）
3. 陰解法の三重対角系を専用に解くか（Thomas 法）、章2の一般の解法に渡すか
4. 時間積分を自前で書くか、線の方法で章4のソルバーに渡すか。
   後者にするなら状態の型が章4のトレイト境界に合うか

## 完了条件

**\\(r > 1/2\\) で発散し、増幅率が von Neumann の予測と一致することを実測する。**

素直にやると観測できないので、手順を指定する。理由は3つある。

**1. 初期条件に \\(\sin(m\pi x)\\) を使わない。** これは離散作用素の**厳密な固有ベクトル**で、
その増幅率は \\(1-4r\sin^2(m\pi\Delta x/2)\\) である。\\(m=1\\) なら \\(r>1/2\\) でも \\(|g|<1\\) で、
発散しない。実測では \\(N=20\\)、\\(r=0.501\\) で**何百万ステップ回しても発散せず**、
\\(\\|u\\|\\) が非正規化数まで落ちてそこで固定される（発散の種が育たない）。

**初期条件は鋸歯 \\(u_j^0 = (-1)^j\\) にする**（または滑らかなモードに小振幅の鋸歯を重ねる）。
前述のとおり発散は鋸歯モードから現れるので、それを最初から与える。

**2. \\(r\\) は 0.5 の「少し上」では足りない。** Dirichlet の厳密な閾値は
\\(N=20\\) で 0.5031 なので、\\(r = 0.500\text{–}0.503\\) は**本当に安定**である。
\\(r = 0.51\\) は厳密閾値の上なので測れるが、余裕を見るなら
\\(r = 0.55, 0.75, 1.0\\) のように明確に上を取る。

**3. 比べる相手は \\(|1-4r|\\) ではない。** \\(r>1/2\\) では \\(1-4r<0\\) なので絶対値が要り、
さらに実測される増幅率は離散波数上の最大値 \\(\max_m|1-4r\sin^2(m\pi/2N)|\\) である。
\\(N=20\\) での両者を並べる:

| \\(r\\) | \\(\max_m\|1-4r\sin^2(m\pi/2N)\|\\) | \\(\|1-4r\|\\) |
|---|---|---|
| 0.55 | 1.186 | 1.200 |
| 0.75 | 1.982 | 2.000 |
| 1.00 | 2.975 | 3.000 |

**実測は中列と数桁の精度で一致し、右列とは1%ほどずれる。** 右列に合わせようとしないこと。
\\(\Delta x \to 0\\) で中列が \\(|1-4r|\\) に近づくところまで見ると、
\\(r \le 1/2\\) が極限条件だという話が閉じる。

余力があれば Crank–Nicolson を実装して、\\(r\\) をいくら大きくしても安定なことを確かめる。
そのとき高波数モードが減衰せず振動として残ること（L-安定でないこと）も一緒に見える。

波動方程式側も同じ形で測れる。\\(\nu\\) を閾値の上に取り、鋸歯初期条件で増幅率の幾何平均を出す。
第1ステップの式（前述）を忘れないこと。
