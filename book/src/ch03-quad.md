# 求積（数値積分）

\\(\int_a^b f(x)\,dx\\) を有限個の \\(f\\) の評価から近似する。

この章の主題は**誤差次数**である。「刻みを半分にしたら誤差が何分の一になるか」を
理論で出し、実測で確かめる。同じ形の議論が章4（ODE の収束次数）と
章7（Monte Carlo の \\(O(N^{-1/2})\\)）で繰り返される。

## Newton–Cotes 型——等間隔の節点

節点を等間隔に取り、\\(f\\) を多項式で補間して、その多項式を厳密に積分する。
**補間の側は章2cで済ませてある。** 補間誤差の式がそのまま求積誤差になるので、
以下の誤差評価はすべてあちらの式の積分だと思ってよい。

### 台形則

1次補間。1区間の誤差は Taylor 展開から

\\[
\int_a^b f - \frac{h}{2}(f(a)+f(b)) = -\frac{h^3}{12}f''(\xi), \qquad h = b-a
\\]

区間を \\(n\\) 等分して足し合わせる（合成台形則）と、区間数 \\(n = (b-a)/h\\) 倍されて

\\[
E = -\frac{(b-a)h^2}{12}f''(\xi) = O(h^2)
\\]

**局所誤差は \\(h^3\\)、大域誤差は \\(h^2\\)。** 1次下がる。合成すると \\(1/h\\) 個の項が積み上がるからで、
章4で局所打ち切り誤差と大域誤差の次数が1つずれるのと同じ理屈である。

### Simpson 則

2次補間。パネル（3点で1つ）の幅を \\(2h\\) として、1パネルの誤差は

\\[
-\frac{h^5}{90}f^{(4)}(\xi)
\\]

\\(h\\) は小区間幅（節点間隔）である。区間を \\(n\\) 等分（\\(n\\) は偶数、\\(h=(b-a)/n\\)）して
\\(n/2\\) 枚のパネルを足し合わせると

\\[
E = -\frac{(b-a)h^4}{180}f^{(4)}(\xi) = O(h^4)
\\]

台形則と同じく局所 \\(h^5\\) から大域 \\(h^4\\) へ1次落ちている。
\\(h\\) を小区間幅と取るかパネル幅 \\(2h\\) と取るかで係数がずれる——
合成則で16倍、1パネルの局所式で32倍。

誤差項に \\(f^{(4)}\\) が出ている。**2次多項式で補間しているのに、3次多項式まで厳密**という意味である。

なぜ1次分得をするか。区間の中点まわりの対称性で、3次の項 \\((x-c)^3\\) の積分が
左右で打ち消し合うからである。奇数次の誤差項が消える。
**対称な公式は1次分得をする**——この構造は Gauss 求積にも、
章4の中点法にも現れる。

### 高次の Newton–Cotes は使わない

節点を増やして次数を上げ続けると壊れる。等間隔節点の高次多項式補間は
Runge 現象（章2c）で端点付近が激しく振動し、さらに重みに負の数が現れて桁落ちする。

高い精度が要るなら、次数を上げるのではなく区間を細かくする（合成）か、
節点の位置を変える（Gauss）。

## Richardson 外挿と Romberg 積分

誤差が \\(h\\) のべきで展開できるとき、**異なる刻みの結果を組み合わせて主要項を消せる。**

台形則 \\(T(h)\\) の誤差が \\(T(h) = I + c_2h^2 + c_4h^4 + \cdots\\) と展開できるなら
（Euler–Maclaurin の公式）、\\(T(h)\\) と \\(T(h/2)\\) を使って

\\[
\frac{4T(h/2) - T(h)}{3} = I + O(h^4)
\\]

**係数 \\(c_2\\) を知らなくても消せる**のがこの技法の要点である。
そして得られた式は合成 Simpson 則と一致する。これを繰り返し適用して表を埋めるのが
**Romberg 積分**で、\\(O(h^2) \to O(h^4) \to O(h^6) \to \cdots\\) と次数が上がっていく。

Richardson 外挿は求積に固有の技法ではない。**「誤差の主要項を打ち消す」**という汎用の道具で、

- 章4の埋め込み型 Runge–Kutta（次数の違う2つの解を比べて誤差を見積もる）
- 数値微分の精度向上——**中心差分** \\(D(h)\\)（誤差が \\(c_2h^2+c_4h^4+\cdots\\)）に
  \\((4D(h/2)-D(h))/3 = O(h^4)\\) と外挿する。台形→Simpson とまったく同じ形である
- 後述の適応分割の誤差推定

が全部同じ枠組みである。

**中心差分そのものは Richardson の産物ではない**ので注意する。前進差分に外挿を掛けても
出てくるのは片側2次公式 \\((-3f(x)+4f(x+h/2)-f(x+h))/h\\) で、中心差分とは別物である
（実測でも別の値になる）。中心差分が \\(O(h^2)\\) なのは Simpson と同じく**対称性**の効果で、
奇数次の誤差項が消えるからである。

## Gauss–Legendre 求積

節点の位置も自由に選ぶ。\\(n\\) 点なら節点 \\(n\\) 個と重み \\(n\\) 個で自由度 \\(2n\\)、
したがって \\(2n\\) 個の条件——\\(1, x, x^2, \ldots, x^{2n-1}\\) を厳密に積分する——を課せる。

\\[
\int_{-1}^{1} f(x)\,dx \approx \sum_{i=1}^{n} w_i f(x_i)
\quad\text{が } \deg f \le 2n-1 \text{ で厳密}
\\]

**\\(n\\) 点で \\(2n-1\\) 次まで厳密。** 等間隔の Newton–Cotes が \\(n\\) 点で
高々 \\(n\\) 次程度なのに対し、節点を動かせる分だけ次数がほぼ倍になる。

節点は **Legendre 多項式 \\(P_n\\) の零点**である。理由は直交性で、
任意の \\(2n-1\\) 次多項式 \\(f\\) を \\(f = qP_n + r\\)（\\(\deg q, \deg r < n\\)）と割ると、
\\(\int qP_n = 0\\) が直交性から従い、残る \\(r\\) は \\(n\\) 点で厳密に積分できる。

重みはすべて正で、桁落ちが起きない。区間 \\([a,b]\\) へはアフィン変換で移す。

この事実は実測しやすい。\\(n\\) 点公式に \\(x^{2n-1}\\) を食わせると機械精度で合い、
\\(x^{2n}\\) を食わせると合わない（ただし \\(n\\) の範囲に条件が付く。完了条件を参照）。

## 適応分割

被積分関数が場所によって荒さの違う——一部で急峻、一部で平坦——とき、
一様な刻みは無駄が多い。**誤差を推定して、大きいところだけ細かくする。**

誤差推定の基本形は、同じ区間を粗い刻みと細かい刻みで積分して差を取ること。
Simpson なら、区間全体の値 \\(S_1 = S(a,b)\\) と半分ずつの和 \\(S_2 = S(a,c)+S(c,b)\\) を比べる。

**ここで \\(1/15\\) を落とさないこと。** 誤差が \\(h^4\\) に比例するので刻みを半分にすると
誤差は \\(1/16\\) になり、差 \\(S_2 - S_1\\) は**細かいほうの誤差の約 \\(2^4-1 = 15\\) 倍**になる。

\\[
|I - S_2| \approx \frac{|S_2 - S_1|}{15}
\\]

実測しても比は 15 に近い値になる。
\\(1/15\\) を落とすと許容判定が15倍保守的になり、無駄に深く分割する。

さらに、採用する値を \\(S_2\\) ではなく \\(S_2 + (S_2-S_1)/15\\) にすれば**1段ぶんの外挿が無料で付く**。
Richardson がここでもう一度出てくる。

差が許容以下なら採用、超えていれば左右に分けて再帰する。

**許容誤差を左右にどう配分するか**が設計判断になる。区間長に比例させるか、
半分ずつにするか。**再帰の深さに上限が要る**のも同じで、
特異点があると無限に分割しようとする。

## Rust の言語機構

### 再帰と所有権

適応分割は再帰で書くのが素直で、再帰は Rust でも普通に書ける。
問題は結果の畳み込み方である。

```rust
// 値を返して足す形
fn quad(a: f64, b: f64) -> f64 { todo!() }

// 出力先を借りて書き込む形
fn quad_into(a: f64, b: f64, out: &mut Vec<(f64, f64)>) { /* ... */ }
```

前者は純関数的で合成しやすい。後者は「どこをどれだけ分割したか」の履歴を残せるが、
`&mut Vec` を再帰の全段に引き回すことになる。区間の分割履歴が欲しいかどうかで決まる。

明示スタックへの書き換え（`Vec<(f64, f64)>` を自分で push/pop する）は、
Rust では再帰と同じくらい素直に書ける。深い再帰でスタックが溢れる問題を避けられるのと、
「次にどの区間をやるか」の順序を自分で制御できる（誤差の大きい区間から処理する優先度付きキューにできる）
のが利点である。

### `Iterator::sum()` で足りるか

合成則の総和は `map().sum()` で書ける。だが**章0の非結合性がここに効く。**

区間数 \\(n\\) を上げていくと、素朴な総和の丸め誤差が求積の打ち切り誤差を**上回る点が来る**。

| 則 | 打ち切り誤差 | 交差する \\(n\\) の目安 | 交差した先 |
|---|---|---|---|
| 合成台形則 | \\(O(h^2)\\) | \\(10^6\\) | 平坦域に入るだけ |
| 合成 Simpson 則 | \\(O(h^4)\\) | \\(10^3\\) | **増加に転じる** |

「交差する」と「精度が悪化する」は別である。完了条件「丸め誤差の床を見る」でこの差を見る。

もう一点。総和誤差の上界 \\(O(nu)\\) は最悪評価で、実測を4桁ほど過大評価する。
誤差の符号が揃わないからで、\\(nu\\) を信じて実測すると全く合わない。

このとき選択肢は、Kahan 加算に切り替えるか、`Iterator` の畳み込みを
分割統治（pairwise summation、誤差が \\(O(u\log n)\\)）にするかである。
どちらも `sum()` ではない。標準の道具で足りるかを、
誤差の見積もりから判断する場所である。

### 積分器を「返す」形

章1では \\(f\\) を受け取る話をした。ここでは**設定を固めた積分器を値として返す**形もありうる。

```rust
// 呼ぶたびに設定を渡す
fn integrate<F: Fn(f64) -> f64>(f: F, a: f64, b: f64, tol: f64) -> f64 { todo!() }

// 設定を持った積分器を作る
struct Adaptive { tol: f64, max_depth: usize }
impl Adaptive {
    fn integrate<F: Fn(f64) -> f64>(&self, f: F, a: f64, b: f64) -> f64 { todo!() }
}
```

後者は Gauss–Legendre の節点と重みを事前計算して持ち回せるという実利がある
（節点の計算は Legendre 多項式の根を求める作業＝章1の Newton 法）。
章7の `rustfft` が「プラン」を持つ API なのも同じ理由で、
**前計算を型に載せる**という共通の形である。

## オラクル

**解析解が取れる被積分関数を選ぶのが最良である**（オラクルが要らなくなる）。

| 積分 | 値 |
|---|---|
| \\(\int_0^1 x^k dx\\) | \\(1/(k+1)\\)。Gauss の次数の壁を測るのに使う |
| \\(\int_0^\pi \sin x\,dx\\) | \\(2\\) |
| \\(\int_0^1 \frac{4}{1+x^2}dx\\) | \\(\pi\\) |
| \\(\int_0^1 e^x dx\\) | \\(e - 1\\) |

適応分割の必要性を出すには、素直でない被積分関数が要る。

- \\(\int_0^1 \sqrt{x}\,dx = 2/3\\)——端点で導関数が発散。誤差次数が落ちる。
  台形則と Simpson 則の誤差次数が同じところまで落ち、\\(h^4\\) の優位が消える
- \\(\int_0^1 \frac{1}{\sqrt{x}}dx = 2\\)——可積分特異点。ただし**閉じた公式では使えない。**
  台形則・Simpson 則は端点 \\(a=0\\) を評価するので `f(0)` が `inf` になり、結果が `inf` になる。
  Gauss–Legendre は節点が内点なのでそのまま通る。閉じた公式で扱うなら \\(x=t^2\\) と変換するか、
  区間を \\([\epsilon, 1]\\) に取る
- 振動する関数——一様な刻みだと節点が振動と共振して壊れることがある

**閉じた公式（端点を評価する）と開いた公式（評価しない）の区別**がここで効く。
Newton–Cotes 型は閉じていて、Gauss 型は開いている。

`scipy.integrate.quad` の値を埋め込む形も取れるが、上のように
解析解のある問題を選べば scipy は要らない。

## 完了条件

### 1. 誤差次数の実測

\\(E = Ch^p\\) なら \\(\log E = \log C + p\log h\\) なので、
**\\(\log h\\) を横軸に取った傾きは \\(+2\\)（台形則）と \\(+4\\)（Simpson 則）である。**
\\(-2, -4\\) になるのは横軸を \\(\log n\\) または \\(\log(1/h)\\) に取ったときで、符号を取り違えると詰まる。

\\(\int_0^1 e^x dx\\) での実測（隣接2点から局所傾きを出したもの）:

\\(n\\) を2倍ずつ増やして \\(p = \log(E_n/E_{n/2})/\log(1/2)\\) を出すと、
\\(n\\) が数十を超えたあたりから台形則で **2.000**、Simpson 則で **4.000** が小数3桁まで安定して出る。

測り方の注意が2つ。全データ点に最小二乗を掛けると丸め誤差の床が傾きを壊すので、
**隣接2点の差分で局所傾きを出す。** そして \\(n = 2, 4, 8, \ldots, 1024\\) と2倍刻みで取る
（Simpson は床に達するまでの点が少ない）。

### 2. 丸め誤差の床を見る

刻みを細かくしすぎると丸め誤差が打ち切り誤差を上回る。ここは則によって見え方が違う。

- **Simpson 則では折れ点がはっきり出る。** \\(n\\) が数千で最小に達し、
  そこから2桁ほど増加に転じる
- **台形則では増加に転じない。** \\(n\\) を \\(10^7\\) まで上げてもノイジーな平坦域に入るだけである

したがってこの課題は Simpson 則でやること。さらに、この床の正体は \\(f\\) の評価の丸めではなく
**総和の誤差**である——同じ実験を Kahan 加算でやると**増加に転じなくなる。**

ただし単調に減り続けるわけでもない。Kahan にすると結果の 1 ulp に張り付いて止まる。
打ち切り誤差が機械精度を下回った後は、床の正体が総和誤差から
**関数値そのものの表現誤差**に置き換わるだけだからである。

これは切り分けられる。節点も関数値も `f64` で厳密に表せる設定を選べば Kahan の誤差は消え、
床の正体が総和誤差だったと確かめられる。前節の `sum()` の話と1本の実験で繋がる。

### 3. Gauss–Legendre の次数の壁

\\(n\\) 点公式が \\(2n-1\\) 次まで厳密で \\(2n\\) 次で崩れることを示す。
\\(\int_0^1 x^k dx = 1/(k+1)\\) を使う——\\([-1,1]\\) 上の \\(x^{2n-1}\\) は奇関数で
節点の対称性から自明に 0 になり、何も検証しないので使わないこと。

**壁が見えるのは \\(n\\) が十数までである。** \\(n\\) 点公式の \\(x^{2n}\\) に対する
相対誤差は \\((n!)^4/((2n)!)^2\\)（\\([0,1]\\) 上）で、これが \\(u\\) を下回ると丸めに埋もれる。
\\(n\\) が小さいうちは実測がこの理論値と数桁一致するが、\\(n=20\\) では
\\(2n-1\\) 次と \\(2n\\) 次が同じ \\(10^{-15}\\) 台になり、壁は完全に消える。
壁が消える \\(n\\) を探すこと自体を課題にすると、章0の話に繋がる。
