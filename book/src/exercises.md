# 演習問題

各章の「完了条件」は数時間から数日かかる実装課題である。ここに置くのは
**紙とペンで数分で終わるもの**で、理論を理解しているかだけを確かめる。
実装に入る前に解くと、実装中に何を疑えばよいかが分かる。

答えは書かない。ただし**数値の答えは末尾に付けた**——導出は自分でやるが、
着地点が合っているかは確かめられる。数値の答えを持たない問題は純粋な導出問題である。

紙で数分では終わらないものが混じっている（行列を組む、数値的に根を求める、など）。
そういう問題は分量で分かるはずなので、時間があるときに回すこと。

## 章0 浮動小数点

1. Kahan 加算の補償 \\(c = (t - s) - y\\) が、実数の算術では恒等的に 0 であることを示せ。
   そのうえで、なぜ `f64` では 0 にならないかを1文で述べよ
2. `1.0 + x == 1.0` となる最大の正の `f64` \\(x\\) を求めよ。
   （ヒント: 最近接偶数丸め。答えは \\(2^{-52}\\) ではない）
3. \\(ax^2+bx+c=0\\) で \\(b > 0\\) のとき、2つの根のうちどちらが桁落ちするか。
   \\(b < 0\\) ならどうか。符号で場合分けした安定な公式を書け
4. 素朴な総和の誤差限界が \\(O(nu)\sum|x_i|\\) なのに、実測が \\(O(\sqrt n\,u)\\) 的に振る舞うのはなぜか

## 章1 根の探索

1. Newton 法を \\(g(x) = x - f/f'\\) の不動点反復と見て、単根で \\(g'(x^\*) = 0\\) を示せ
2. 重複度 \\(m\\) の根で Newton の収束比が \\((m-1)/m\\) になることを、
   \\(f = (x-x^\*)^m h(x)\\)、\\(h(x^\*) \neq 0\\) として示せ
3. 割線法の誤差漸化式 \\(e_{n+1} \approx Ce_ne_{n-1}\\) から \\(p^2 = p+1\\) を導け。
   途中で \\(C \neq 0\\) をどこで使ったか指摘せよ
4. 二分法で \\(|e_{n+1}|/|e_n|\\) が 10 を超える具体例を1つ作れ
   （区間と \\(f\\) を書けばよい。数値実験で確かめられる）

## 章2 密行列の線形代数

1. \\(\kappa_2(A^\top A) = \kappa_2(A)^2\\) を特異値で示せ
2. Householder 行列 \\(H = I - 2vv^\top/(v^\top v)\\) が直交かつ対称であることを確かめよ。
   \\(H^2 = I\\) も示せ
3. LU 分解の flop 数が \\(\tfrac23 n^3\\) であることを、消去の3重ループから数えよ
4. \\(\\|e\\|_A = \sqrt{e^\top Ae}\\) がノルムであるために \\(A\\) に何が要るか。
   CG の誤差評価が2-ノルムでは成立しないのはなぜか

## 章3 求積

1. Simpson 則が3次多項式まで厳密であることを、区間の中点まわりの対称性から示せ
   （\\(\int (x-c)^3\\) を計算すればよい）
2. \\((4T(h/2) - T(h))/3\\) が合成 Simpson 則と一致することを、\\(n=2\\) の場合に手で確かめよ
3. Simpson の誤差が \\(h^4\\) に比例することから、\\(S_2 - S_1\\) が
   細かいほうの誤差の約 15 倍になることを示せ
4. \\(n\\) 点 Gauss–Legendre が \\(2n-1\\) 次まで厳密であることを、
   \\(f = qP_n + r\\) の割り算と直交性から示せ

## 章4 常微分方程式

1. 陽的 Euler の安定領域 \\(|1+z| \le 1\\) から、\\(y' = \lambda y\\)（\\(\lambda < 0\\) 実数）に対する
   刻み幅の条件 \\(h \le 2/|\lambda|\\) を導け
2. 台形則の \\(R(z) = (1+z/2)/(1-z/2)\\) を導き、\\(z \to -\infty\\) の極限を求めよ。
   後退 Euler との違いが stiff で何を引き起こすか1文で
3. 局所誤差が \\(h^{p+1}\\) に比例することから、刻み幅制御の指数が \\(1/(p+1)\\) になることを導け
4. RK4 の \\(R(z)\\) を求めよ（\\(y'=\lambda y\\) に4段を適用すればよい）。
   4次多項式 \\(1+z+z^2/2+z^3/6+z^4/24\\) になることを示せ。
   実軸上の安定区間の端は閉形式では出ないので、**数値的に**求める
   （紙で終わるのは前半だけ）

## 章4b 確率微分方程式

1. 伊藤の補題を \\(f(x) = x^2\\)、\\(dX = a\,dt + b\,dW\\) に適用して \\(d(X^2)\\) を書け。
   通常の連鎖律との差はどの項か
2. \\(\mathbb{E}[(\Delta W)^2] = \Delta t\\) を使って、Milstein の補正項
   \\(\tfrac12 bb'((\Delta W)^2 - \Delta t)\\) の期待値が 0 であることを示せ。
   では、なぜこの項を足すと**強**収束次数が上がるのか
3. \\(b\\) が定数（加法ノイズ）のとき、Milstein が Euler–丸山と一致することを示せ。
   これが「加法ノイズでは Euler–丸山の強次数が 1.0 になる」ことの理由になっているか
4. 幾何ブラウン運動で \\(\mathbb{E}[\hat X_N] = X_0(1+\mu\Delta t)^N\\) を導け
   （増分と状態の独立性を使う）

## 章5 最適化

1. Wolfe の曲率条件と \\(\nabla f_k^\top d_k < 0\\) から \\(s_k^\top y_k > 0\\) を導け
2. \\(f = \frac12 x^\top Ax\\) について \\(f(x) - f^\* = \frac12\\|e\\|_A^2\\) を示せ。
   これが「関数値の収束率が誤差ノルムの2乗になる」ことの説明になっているか
3. \\((H + \lambda I)^{-1}\nabla f\\) が \\(\lambda \to \infty\\) でどの方向に近づくか。
   信頼領域法との関係を1文で
4. Rosenbrock の Hessian を \\((1,1)\\) で計算し、その固有値を求めよ
   （本文の値と突き合わせられる）

## 章6 自動微分

1. \\(\sqrt{a+b\varepsilon}\\)、\\(\log(a+b\varepsilon)\\)、\\((a+b\varepsilon)^k\\)（\\(k\\) は実数）を求めよ。
   \\(a=0\\) や \\(a<0\\) で何が起きるか（本文の「非平滑点」と繋げよ）
2. 前進差分の誤差 \\(\frac h2|f''| + \frac{2u|f|}{h}\\) を最小化して \\(h^\*\\) と \\(E(h^\*)\\) を求めよ。
   \\(f = \exp\\)、\\(x=1\\) で数値を出し、末尾の答えと合うか確かめよ
3. 中心差分について同じ計算をして \\(h_{\text{opt}}\\) と \\(E(h_{\text{opt}})\\) を求めよ。
   **丸め誤差の項が \\(2u|f|/h\\) でなく \\(u|f|/h\\) になる**（分母が \\(2h\\) だから）点に注意
4. \\(f:\mathbb{R}^n\to\mathbb{R}^m\\) のヤコビ行列全体が欲しいとき、
   前進と逆のどちらが有利か。\\(n, m\\) の条件で答えよ

## 章7 FFT と Monte Carlo

1. \\(E_{k+N/2} = E_k\\) を示せ。これが無いと Cooley–Tukey の後半の式が出ないことを確かめよ
2. \\(N=8\\) の bit-reversal 順列を書き下せ
3. Parseval の等式 \\(\sum_n|x_n|^2 = \frac1N\sum_k|X_k|^2\\) の正規化定数 \\(1/N\\) を、
   本文の DFT の定義から導け
4. \\(N^{-p/d}\\) と \\(N^{-1/2}\\) を比べて交差条件 \\(d > 2p\\) を導け。
   Simpson（\\(p=4\\)）と台形則（\\(p=2\\)）でそれぞれ \\(d\\) はいくつか
5. \\(\int_{[0,1]^d}\prod x_i\,dx = 2^{-d}\\) の相対標準偏差
   \\(\sqrt{3^{-d}-4^{-d}}/2^{-d}\\) を導き、\\(d=32\\) での値を計算せよ

## 章8 差分法

1. Crank–Nicolson の増幅率 \\(g = \dfrac{1-2r\sin^2(k\Delta x/2)}{1+2r\sin^2(k\Delta x/2)}\\)
   を導き、すべての \\(r>0\\) で \\(|g|\le1\\) を示せ
2. \\(r = 1/2\\) のとき陽解法のスキームが
   \\(u_j^{n+1} = (u_{j+1}^n + u_{j-1}^n)/2\\) になることを示せ
3. Dirichlet 境界での厳密な閾値 \\(r \le 1/(2\cos^2(\pi/2N))\\) を、
   \\(\max_m|1-4r\sin^2(m\pi/2N)| \le 1\\) から導け。
   \\(N=20\\) で評価し、\\(1/2\\) をわずかに上回ることを確かめよ
4. 波動方程式の leapfrog スキームに von Neumann 解析を適用し、
   CFL 条件 \\(\nu \le 1\\) を導け

## 章8b 有限要素法

1. 一様メッシュ（幅 \\(h\\)）の1次元 P1 要素で、**境界節点を含む全体の**剛性行列を組め。
   両端の対角が \\(1/h\\)、内部の対角が \\(2/h\\) になることを確かめよ。
   内部節点だけを取り出すと \\(\frac1h\,\mathrm{tridiag}(-1,2,-1)\\) になる
2. 同じ設定で全体の質量行列を組め。両端の対角が \\(2h/6\\)、内部が \\(4h/6\\) になる。
   **全体行列の**全成分の和が \\(|\Omega|\\) に等しいことを確かめよ
   （内部だけに落とすと \\(1 - \frac{4}{3N}\\) になり、一致しない）
3. \\(\sum_j \phi_j \equiv 1\\) から、**全体の**剛性行列の行和がゼロであることを示せ。
   内部節点だけに落とすと端の行が \\(1/h\\) になり、成り立たないことも確かめよ
4. 境界条件を「行を潰す」（該当行を \\(e_i^\top\\) に置換）方式で課すと、
   剛性行列の対称性が壊れることを \\(3\times3\\) の例で確かめよ。
   対称性を保つ課し方を1つ書け
5. 1次元 P1 が節点で厳密になる理由を述べよ
   （ヒント: 離散方程式が差分法の3点公式と一致する）
