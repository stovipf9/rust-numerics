# 固有値問題

[密行列の線形代数](ch02-linalg.md)の続きで、その道具立てをそのまま使う。

この章が要る理由は、**本の他の場所が固有値を使い倒しているのに、
その求め方をどこにも書いていない**からである。[密行列の線形代数](ch02-linalg.md)は \\(\kappa_2 = \sigma_1/\sigma_n\\) を
特異値で定義し、[最適化](ch05-optim.md)は Hesse 行列の固有値で条件数を出し、[PDE の差分法](ch08-pde.md)は離散 Laplacian の
固有値で安定性を出す。全部「どこかから降ってくる量」として扱われていた。

## 特性多項式で解いてはいけない

固有値の定義は \\(\det(A - \lambda I) = 0\\) だが、これは計算の手順ではない。理由が2つある。

**1つめは代数的な事実。** **一般の**5次以上の多項式は根号で解けない（Abel–Ruffini。
\\(x^5-2=0\\) のような個別の式は解ける）。そして固有値は任意次数の多項式の根になりうる
（コンパニオン行列）。したがって

> \\(n \ge 5\\) の固有値アルゴリズムは、**原理的に反復でしかありえない。**

**四則演算と根号だけを有限回**使って固有値に到達する手続きは存在しない。
LU や QR とはここが決定的に違う。

2つめは数値的な事実で、こちらが実害である。 多項式の根は係数に対して
極端に敏感になりうる。Wilkinson の多項式 \\(\prod_{k=1}^{20}(x-k)\\) が有名な例で、
係数を1つだけ相対 \\(10^{-10}\\) 程度動かすと、根が複素平面に大きく散る。

\\(A\\) から特性多項式の係数を作る段階でこの増幅が起きるので、
**元の固有値問題がどれだけ良条件でも、多項式経由にした瞬間に壊れる。**
[密行列の線形代数](ch02-linalg.md)の「正規方程式にすると \\(\kappa^2\\) になる」とまったく同じ構図——
**解法が問題を悪くしている。**

## べき乗法

\\(A\\) を繰り返し掛ける。固有ベクトルで展開すると、絶対値最大の固有値の成分だけが残る。

\\[
v_{k+1} = \frac{A v_k}{\\|A v_k\\|}
\\]

成り立つには仮定が要る——\\(A\\) が対角化可能（「固有ベクトルで展開」がこれを前提している）、
**狭義の**支配 \\(|\lambda_1| > |\lambda_2|\\)、初期ベクトルが \\(x_1\\) 方向の成分を持つこと。
等号だと収束しない。\\(\mathrm{diag}(1,-1)\\) は実対称だが \\(|\lambda_1| = |\lambda_2|\\) なので、
反復は2点を永久に往復する。**「対称なら安心」ではない。**

**固有ベクトル**の誤差は \\(r = |\lambda_2/\lambda_1|\\) の比で減る——線形収束で、
収束比は固有値の分離度そのものである。\\(r \approx 1\\) だと使い物にならない。

ここで**何の誤差を測っているかで指数が変わる。** 対称行列では、Rayleigh 商
\\(v^\top Av / v^\top v\\) で固有値を推定すると、その誤差は **\\(r^2\\)** で減る
（停留点なので1次の項が消える）。固有ベクトルの誤差は \\(r\\)、固有値の誤差は \\(r^2\\)。
実測でどちらを見ているかを意識しないと、理論と合わないように見える。

得られるのは支配固有対だけである。しかし行列を要求しない（必要なのは \\(v \mapsto Av\\) だけ）ので、
疎行列や matrix-free の作用素にそのまま当たる。[有限要素法](ch08b-fem.md)の `LinearOperator` がここでも効く。

### 逆べき乗法とシフト

\\((A - \sigma I)^{-1}\\) にべき乗法を当てると、\\(\sigma\\) に最も近い固有値が支配的になる。
\\(\sigma\\) を目標の固有値の近くに置けば、収束比が劇的に良くなる。

ここで奇妙なことが起きる。\\(\sigma\\) を固有値に近づけるほど \\(A - \sigma I\\) は特異に近づき、
**わざと極端な悪条件の系を解くことになる。** [密行列の線形代数](ch02-linalg.md)の教えに反するように見えるが、これでよい。
誤差が増幅される方向が、まさに求めたい固有ベクトルの方向だからである。
「条件数が悪い＝常に駄目」ではない、という反例としても読める。

なお \\((A-\sigma I)^{-1}\\) を作ってはいけない。毎反復 \\((A-\sigma I)x = v_k\\) を解く
（LU を1回作って使い回す）。[密行列の線形代数](ch02-linalg.md)の「逆行列は作らない」がそのまま適用される。

### Rayleigh 商反復

シフトを固定せず、現在の近似から

\\[
\sigma_k = \frac{v_k^\top A v_k}{v_k^\top v_k}
\\]

と更新し続ける。対称行列では**3次収束**する。反復ごとに \\(\sigma\\) が変わるので
LU を毎回作り直すことになり、1反復が高い。それでも回数が圧倒的に少ない。

対称行列では**収束自体は保証される**（残差が単調に減る）。予測できないのは
「収束するか」ではなく**どの固有対に着地するか**で、狙った固有値の近くから始めても
別のものを掴むことがある。循環して収束しないのは非対称に特有の現象である。

## QR 法

実用の稠密固有値ソルバーの本体。\\(A_k = Q_k R_k\\) と分解して \\(A_{k+1} = R_k Q_k\\) と積を逆順にする。
\\(A_{k+1} = Q_k^\top A_k Q_k\\) なので**直交相似変換**で、固有値は変わらない。
これを繰り返すと、シフトを入れれば上三角に収束する。

素朴にやると1反復が \\(O(n^3)\\) で、反復回数を掛けると使えない。
実装は2段階になる。

1. **Hessenberg 化**（対称なら三重対角化）——Householder 鏡映で \\(O(n^3)\\) を1回だけ払う。
   副対角より下をゼロにした形にする
2. **シフト付き QR 反復**——Hessenberg 形は QR 反復で保たれるので、1反復が \\(O(n^2)\\) になる

この「一度だけ高い前処理をして、以降の反復を安くする」構造は、[FFT と Monte Carlo](ch07-fft-mc.md)のプランや
[求積](ch03-quad.md)の Gauss 節点の事前計算と同じ形である。

## 対称と非対称はまったく違う問題

同じ「固有値問題」という名前だが、性質が大きく違う。

| | 対称（Hermite） | 非対称 |
|---|---|---|
| 固有値 | 必ず実 | 複素になりうる |
| 固有ベクトル | 直交基底が取れる | 一般には斜交。重複すると足りないことすらある |
| 摂動 | \\(\|\delta\lambda\| \le \\|\delta A\\|_2\\)（Weyl） | 増幅されうる |
| 対角化 | 常に可能 | Jordan 形しか取れない場合がある |

**非対称の固有値には条件数がある。** \\(\lambda_i\\) が**単根**で、左右の固有ベクトルを
\\(\\|x_i\\|_2 = \\|y_i\\|_2 = 1\\) と**正規化**したとき、その条件数は

\\[
\frac{1}{|y_i^{\mathsf H} x_i|}
\\]

である。**正規化を落とすと意味を持たない**——固有ベクトルはスカラー倍の自由度があるので、
正規化しない \\(1/|y^\top x|\\) は \\(x\\) を定数倍するだけで任意に動く。
\\(\begin{pmatrix}1 & 1000\\\\ 0 & 2\end{pmatrix}\\) の \\(\lambda=1\\) で試すと、
正規化なしでは 1（＝完全に良条件）と出るが、正規化すると 1000 になる。実際の感度は後者である。

Jordan ブロックに近い行列ではこれが発散する。極端な場合、\\(\varepsilon\\) の摂動が
\\(\varepsilon^{1/m}\\) の固有値変化を生む（**\\(m\\) は Jordan ブロックの大きさ**であって、
重複度ではない。重複度が \\(m\\) でも対角化可能なら——たとえば \\(5I\\) ——
摂動は線形にしか効かない）。

一方**対称なら固有値は常に完全に良条件**で、摂動は線形にしか効かない。
実務で「対称かどうか」を最初に確かめるのはこのためである。

## SVD との関係

\\(A = U\Sigma V^\top\\) の特異値は \\(A^\top A\\) の固有値の平方根である。
だが[密行列の線形代数](ch02-linalg.md)で見たとおり、**\\(A^\top A\\) を作った瞬間に条件数が二乗される。**

実用の SVD は \\(A^\top A\\) を経由せず、\\(A\\) を直接**二重対角化**（Golub–Kahan）してから
その二重対角行列に反復を当てる。「数学的に等価な変形が、数値的には等価でない」の
もう一つの例で、[密行列の線形代数](ch02-linalg.md)の最小二乗と同じ教訓である。

## 大規模・疎な場合——Lanczos

\\(n\\) が大きいと \\(O(n^3)\\) は払えないし、そもそも \\(A\\) を格納できないこともある。

Lanczos 法は対称行列に対し、Krylov 部分空間 \\(\mathrm{span}\\{v, Av, A^2v, \ldots\\}\\) の
正規直交基底を作りながら、\\(A\\) を小さな**三重対角行列**に射影する。
その小行列の固有値（Ritz 値）が、\\(A\\) のスペクトルの端の固有値に速く収束する。

- **必要なのは \\(v \mapsto Av\\) だけ**である。[密行列の線形代数](ch02-linalg.md)の共役勾配法とまったく同じ要求で、
  同じ Krylov 部分空間を使っている。CG と Lanczos は同じものの別の顔である
- 有限精度では直交性が失われ、**同じ固有値が何度も現れる**（ghost eigenvalue）。
  再直交化が要る。「数学的には直交するはず」が丸めで壊れる典型例

## Rust の言語機構

### 複素固有値をどう返すか

実行列でも固有値は複素になる。ここで戻り値の型が決まる。

- `Vec<Complex<f64>>` を返す——素直だが、対称行列でも複素型を扱わされる。
  `num-complex` への依存が入る（[FFT と Monte Carlo](ch07-fft-mc.md)と共通）
- **実 Schur 形**を返す——実行列のまま、対角に \\(1\times1\\) と \\(2\times2\\) のブロックを並べる。
  \\(2\times2\\) ブロックが共役対の複素固有値を表す。実算術で完結するが、
  呼び出し側がブロックを解釈する必要がある

LAPACK は両方の API を持っている。**「複素数を型で持つか、実の構造で持つか」**という
データ表現の選択で、[FFT と Monte Carlo](ch07-fft-mc.md)の `Complex<f64>` 対 SoA と同じ種類の判断である。

### 対称と非対称を型で分けるか

上で見たとおり、この2つは別の問題である。設計の選択肢が出る。

- 同じ関数で受けて実行時に対称性を検査する——判定に許容が要る（浮動小数点なので厳密対称は稀）
- `SymmetricMatrix` のようなラッパ型を作る——**「対称行列に非対称アルゴリズムを当てる」が
  型で防げる**。構築時に一度検査すれば以降ゼロコスト。[浮動小数点と丸め](ch00-float.md)の「NaN を型で防ぐか」と同じ形
- そもそも別の関数にする——最も単純。呼び分けを間違えても静かに遅くなるだけ

### 固有値だけか、固有ベクトルもか

固有ベクトルまで求めると計算量が大きく増える。API がここで分岐する。
戻り値の型を変えるか、フラグを取るか、ビルダにするか。
[密行列の線形代数](ch02-linalg.md)の「分解済みを型で表す」と同じ問いが、別の形で出ている。

### 反復の停止

[根の探索](ch01-roots.md)の再訪だが、対象が行列全体になる。何をもって「収束した」とするか——
副対角要素の大きさか、Ritz 値の変化か、残差 \\(\\|Av - \lambda v\\|\\) か。
残差は計算できるが固有ベクトルが要る。副対角は安いが意味が間接的である。

## オラクル

固有値は**閉じた形で答えが分かる行列**が豊富にあるので、外部の値を埋め込む必要がほとんどない。

| 行列 | 固有値 |
|---|---|
| 対角行列・三角行列 | 対角成分そのもの |
| 回転行列 \\(\begin{pmatrix}\cos\theta & -\sin\theta\\\\ \sin\theta & \cos\theta\end{pmatrix}\\) | \\(e^{\pm i\theta}\\)（実行列だが複素固有値） |
| \\(n\times n\\) の \\(\mathrm{tridiag}(-1,2,-1)\\) | \\(4\sin^2\dfrac{k\pi}{2(n+1)}\\)、\\(k=1,\ldots,n\\) |
| [最適化](ch05-optim.md)の Rosenbrock の Hesse 行列（最小点） | \\(2\times2\\) なので手で解ける |

3行目が特に良い。**定数倍と符号を除いて[PDE の差分法](ch08-pde.md)の離散 Laplacian**なので、
ここで作ったソルバーがその安定性解析の \\(\lambda_m\\) を再現するか確かめられる。
しかも \\(n\\) を自由に上げられ、固有値の分離度も分かっているので、
べき乗法の収束比 \\(|\lambda_2/\lambda_1|\\) の検証にそのまま使える。

不変量（`proptest` 向け）:

- \\(\mathrm{tr}(A) = \sum \lambda_i\\)、\\(\det(A) = \prod \lambda_i\\)
- 残差 \\(\\|Av_i - \lambda_i v_i\\|\\) が小さい
- 対称行列なら固有ベクトルが直交する
- 直交相似変換で固有値が保たれる（QR 反復の各段で確かめられる）

1. 複素固有値を `Complex<f64>` で返すか、実 Schur 形で返すか
2. 対称と非対称を型で分けるか、実行時に検査するか、別の関数にするか
3. 固有ベクトルの有無を API でどう表すか
4. べき乗法・Lanczos を行列に対して書くか、\\(v \mapsto Av\\) のトレイトに対して書くか
   （[有限要素法](ch08b-fem.md)の `LinearOperator` と同じものを先に切るか）
5. 反復の停止条件に何を使うか

## 完了条件

- **べき乗法の収束比を実測する。** \\(\mathrm{tridiag}(-1,2,-1)\\) なら
  \\(\lambda_1, \lambda_2\\) が閉じた形で分かるので予測と直接比べられる。
  **固有ベクトルの誤差と固有値の誤差を両方測ること**——前者が \\(r\\)、後者が \\(r^2\\) で減る。
  片方だけ測って「理論と合わない」と判断しやすい箇所である
- **対称三重対角の固有値が閉じた形と一致する**。\\(n\\) を上げても保たれるか
- **特性多項式経由と比べて精度差を出す。** \\(\prod_{k=1}^{n}(x-k)\\) を展開してから
  根を求める経路と、行列から直接求める経路を比べる。\\(n\\) を上げていくと
  前者が先に崩れる \\(n\\) がある
- 余力があれば Rayleigh 商反復を実装して、対称行列で3次収束を実測する
  （[根の探索](ch01-roots.md)の収束次数の測り方がそのまま使える）

## 既製クレートの扱い

固有値ソルバーは**自作の敷居が高い**（シフト戦略、デフレーション、収束判定の作り込みが本体）。
[密行列の線形代数](ch02-linalg.md)で選んだクレートが何を提供しているかをまず読み、
べき乗法と Lanczos だけ自作する——という切り分けが現実的である。
QR 法は「読んで理解する」対象に置いてよい。
