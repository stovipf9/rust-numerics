# 根の探索

\\(f(x) = 0\\) を満たす \\(x\\) を求める。最も単純な非線形問題で、
この章で決めた設計が[常微分方程式](ch04-ode.md)（陰的解法の内側）と[最適化](ch05-optim.md)（多変数 Newton）にそのまま効く。

## 手法

### 二分法

\\(f\\) が \\([a,b]\\) で連続で \\(f(a)f(b) < 0\\) なら、中間値定理より \\((a,b)\\) に根がある。
中点で符号を見て、根を含む側に区間を狭める。

\\(n\\) 回後の区間幅は \\((b-a)/2^n\\) で、根の位置を中点に取れば誤差は

\\[
|e_n| \le \frac{b-a}{2^{n+1}}
\\]

これは \\(f\\) の性質に一切依存しない上界である。微分可能性も要らない。
`f64` の精度まで詰めるのに必要な反復回数は、初期区間幅を \\(1\\) として \\(\log_2(1/10^{-16}) \approx 53\\) 回。
つまり **常に約50回で終わる**——速くも遅くもならない。

**収束の「次数1」は誤差の上界についての話である。** 上界が公比 \\(1/2\\) で減る、
すなわち R-線形収束であって、実際の誤差比 \\(|e_{n+1}|/|e_n|\\) は \\(1/2\\) ではなく、
上に有界ですらない。したがって \\(\lim |e_{n+1}|/|e_n|\\) は存在せず、標準的な定義では二分法は Q-線形収束しない。
後で収束次数を実測するとき、二分法だけ散布図が線に見えないのはこのためである。

そしてこの中で二分法だけが収束を保証する（後述の Brent はその保証を引き継ぐ）。
この保証の有無が、以下の手法との本質的な対比になる。

### Newton–Raphson

\\(x_n\\) での接線が \\(x\\) 軸と交わる点を次の近似とする。

\\[
x_{n+1} = x_n - \frac{f(x_n)}{f'(x_n)}
\\]

収束次数を出す。\\(x^\*\\) を根、\\(e_n = x_n - x^\*\\) とする。\\(f\\) が \\(x^\*\\) を含む
区間で \\(C^2\\) 級で、その区間で \\(f'\neq 0\\) とし、\\(f\\) を \\(x_n\\) のまわりで
Taylor 展開して \\(f(x^\*) = 0\\) を使うと（\\(\xi\\) は \\(x_n\\) と \\(x^\*\\) の間の点）

\\[
0 = f(x_n) - e_n f'(x_n) + \frac{e_n^2}{2}f''(\xi)
\\]

これを漸化式に入れて整理すると

\\[
e_{n+1} = \frac{f''(\xi)}{2 f'(x_n)} e_n^2
\\]

**2次収束。** ただし右辺の分母に \\(f'\\) がいる。したがって

\\[
f'(x^\*) \neq 0 \quad(\text{単根})
\\]

が2次収束の条件である。定理として述べるならもう1つ、\\(x_0\\) が \\(x^\*\\) に十分近いことが要る
（収束は局所的にしか保証されない）。誤差の桁数が毎回およそ倍になるので、収束が始まれば
\\(10^{-2} \to 10^{-4} \to 10^{-8} \to 10^{-16}\\) と3〜4回で機械精度に達する。

上の議論は一点 \\(\xi\\) を使った Taylor 剰余の等式に乗っている。
**多変数ではこの等式が使えない**（ベクトル値の平均値定理は単一の中間点では書けない）ので、
積分形の剰余を使う。標準的な仮定は、求根する写像を \\(F\\) として

\\[
F'(x^\*) \text{ が正則}, \qquad F' \text{ が } x^\* \text{ の近傍で Lipschitz 連続}
\\]

である。**これは次元の話ではない。** \\(F \in C^2\\) なら \\(F'\\) は局所 Lipschitz なので
上の仮定は自動的に満たされる（\\(C^2\\) のほうが強い）し、逆に1変数でも
\\(F'\\) が Lipschitz でなければ2次収束しない——たとえば \\(F(x) = x + x\sqrt{|x|}\\) は
\\(C^1\\) で \\(F'(0)=1 \neq 0\\) だが、収束次数は 1.5 に落ちる。

仮定の強さが実際に変わるのは、求根から最適化に乗り換えるときである。
[最適化](ch05-optim.md)は \\(\nabla f = 0\\) を解くので \\(F = \nabla f\\)、そのヤコビ行列は Hesse 行列——
つまり目的関数に課される条件は「\\(\nabla^2 f\\) が Lipschitz」であり、
\\(f \in C^2\\)（\\(\nabla^2 f\\) が連続なだけ）より1段強い。これは1変数の最適化でも同じである。

壊れ方も知っておく。\\(f'(x_n)\\) がゼロに近いと更新量が発散する。初期値が悪いと
2点を行き来する周期解に落ちることがある。収束は**局所的**にしか保証されない——
「十分近ければ2次で収束する」であって、遠くからの収束は何も言えない。

### 重根で何が起きるか

\\(f(x) = (x-1)^2\\) に Newton を当てると、\\(f/f' = (x-1)^2 / (2(x-1)) = (x-1)/2\\) なので

\\[
x_{n+1} = x_n - \frac{x_n - 1}{2} = \frac{x_n + 1}{2}
\quad\Longrightarrow\quad
e_{n+1} = \frac{1}{2} e_n
\\]

**誤差が半分になるだけ**で、これは1次収束である。二分法と同じ速さまで落ちた。
一般に重複度 \\(m\\) の根では収束比 \\((m-1)/m\\) の線形収束になる。
重複度が既知なら \\(x_{n+1} = x_n - m f/f'\\) と修正すれば2次が戻る。

この例は**手で解けるので実測の答え合わせに使える**——傾きがちょうど 1 になるはずで、
収束比もちょうど \\(1/2\\) になるはずである。

### 割線法

導関数が手に入らない、あるいは高いとき、\\(f'(x_n)\\) を差分商で置き換える。

\\[
x_{n+1} = x_n - f(x_n)\frac{x_n - x_{n-1}}{f(x_n) - f(x_{n-1})}
\\]

\\(f\\) が \\(C^2\\) 級、\\(x^\*\\) が単根、\\(x_0, x_1\\) が \\(x^\*\\) に十分近いとすると、
誤差の漸化式は

\\[
e_{n+1} \approx C\, e_n e_{n-1}, \qquad C = \frac{f''(x^\*)}{2f'(x^\*)}
\\]

になる。収束次数 \\(p\\) を \\(|e_{n+1}| \sim K|e_n|^p\\) と置いて代入すると \\(p^2 = p + 1\\) が出る。
この代入が意味を持つには \\(C \neq 0\\)、すなわち \\(f''(x^\*) \neq 0\\) が要る
（\\(f''(x^\*)=0\\) なら次数はもっと上がる）。正の解が

\\[
p = \frac{1+\sqrt5}{2} \approx 1.618
\\]

黄金比である。2次には届かないが、1反復あたりの \\(f\\) の評価が1回で済む
（Newton は \\(f\\) と \\(f'\\) で2回）。\\(f\\) の評価が高い問題では
評価回数あたりの効率で Newton を上回りうる——\\(1.618 > \sqrt{2} \approx 1.414\\) だからである。

### 不動点反復

\\(f(x)=0\\) を \\(g(x) = x\\) の形に書き換えて \\(x_{n+1} = g(x_n)\\) を回す。
書き換え方は一意でなく、選び方で収束するかどうかが変わる。

\\(g\\) が \\(x^\*\\) の近傍で \\(C^1\\) で \\(|g'(x^\*)| < 1\\) とする。\\(g'\\) の連続性から、
\\(g(I) \subseteq I\\) を満たす閉近傍 \\(I \ni x^\*\\) が取れる（ここが要る——これが無いと
\\(x_n\\) が近傍から出て平均値定理が使えない）。\\(x_0 \in I\\) なら以降すべて \\(I\\) に留まり、
平均値定理から

\\[
e_{n+1} = g(x_n) - g(x^\*) = g'(\eta)\, e_n
\\]

したがって収束比は \\(|g'(x^\*)|\\) で1次収束。
さらに \\(g\\) が \\(C^2\\) で \\(g'(x^\*) = 0\\) なら1次の項が消えて2次になる
（\\(C^1\\) だけなら超1次収束までしか言えない）——Newton 法は
\\(g(x) = x - f/f'\\) と置いた不動点反復であり、単根では \\(g'(x^\*) = 0\\) が成り立つ。
これが Newton の2次収束の別の見方である。

Banach の不動点定理の縮小写像がこの話の一般形で、[常微分方程式](ch04-ode.md)の陰的解法で
同じ議論をもう一度使う。

### Brent 法——なぜ混ぜるのか

実用のソルバー（`scipy.optimize.brentq` など）は単一の手法ではない。
二分法は保証があるが遅く、割線・逆二次補間は速いが保証がない。
Brent 法は区間を保持し続けて（＝二分法の保証を捨てず）、
補間が区間内に収まり十分縮んでいる間はそちらを使い、条件を満たさない反復では
二分法に落とす。

「速いが保証のない手法」と「遅いが保証のある手法」を、保証を持つ側を骨格にして混ぜる——
これは数値計算で繰り返し出るパターンで、[求積](ch03-quad.md)の適応分割にも[最適化](ch05-optim.md)の直線探索にも同じ形が現れる。

## 停止条件——どれも壊れる

反復をいつ止めるか。候補は次のとおりで、**どれにも壊れる入力がある。**

| 条件 | 壊れる場合 |
|---|---|
| \\(\|f(x_n)\| < \varepsilon\\) | \\(f\\) が根の近くで平坦（\\(f' \approx 0\\)、重根）だと、根から遠くても \\(\|f\|\\) が小さい。逆に \\(f\\) が急峻だと、根に十分近くても止まらない |
| \\(\|x_{n+1} - x_n\| < \varepsilon\\) | 収束が遅い（線形で収束比が 1 に近い）と、根から遠くても刻みが小さくなって止まる |
| 相対誤差 \\(\|x_{n+1}-x_n\| / \|x_{n+1}\|\\) | 根が 0 の近くだと分母が壊れる |

実用のソルバーは複合条件を使う——絶対と相対の混合 \\(\varepsilon_{\text{abs}} + \varepsilon_{\text{rel}}|x_n|\\) に、
最大反復回数を付ける、など。**どれを選ぶか、呼び出し側に選ばせるかが設計判断**で、
これは[浮動小数点と丸め](ch00-float.md)の `approx` の絶対/相対の話と同じ構造である。

もう一つ: 反復回数の上限に達したとき、「収束しなかった」と「収束しなかったが現在の推定値はこれ」は
別の情報である。後者を捨てるかどうかは API の設計で決まる。

## 収束次数を実測する

理論値を信じずに測る。\\(|e_{n+1}| \sim K|e_n|^p\\) の両辺の対数を取ると

\\[
\log|e_{n+1}| = p \log|e_n| + \log K
\\]

\\(\log|e_n|\\) を横軸、\\(\log|e_{n+1}|\\) を縦軸に取った傾きが \\(p\\)。

実測時の注意がある。**どれか1つでも欠けると理論値は出ない。**

1. 真の根が要る。\\(e_n = x_n - x^\*\\) を計算するのに \\(x^\*\\) が必要なので、
   解析解が取れる問題か、下のオラクルを使う
2. \\(e_n = 0\\) を**含むペアを回帰から外す**（点だけ捨てて前後を詰め、隣接させ直してはいけない。
   結果が変わる）。反復が根に厳密に当たることは実際に起きる——
   二分法では列の中に \\(e_n = 0\\) が現れることがあり、
   \\(\log 0 = -\infty\\) なので、素直に書いた回帰は NaN を返すか panic する
3. 機械精度に達した後の点を除く。下限は \\(10^{-16}\\) ではなく
   \\(\mathrm{ulp}(x^\*)\\) の数倍である——根が \\(\approx 2\\) なら \\(\mathrm{ulp}(2) = 4.4\times10^{-16}\\)。
   実用上は上下に窓を切って、その内側の点だけを使う
4. 残った点数を一緒に報告する。ここでいう「有効点」は回帰に使うペアの個数である。
   超線形な手法では有効点が数個しか残らず、「回帰」と呼べる規模にならないことがある

窓の取り方で結果は動く。割線法の理論値は 1.618 だが、問題と窓を変えると
**傾きは 1 の近くまで落ちることがある**——窓を切らないと、末尾で機械精度に張り付いた
同じ大きさの誤差が並び、そこが回帰を1次側に引っ張るからである。

もう1つ、**誤差列は \\(x_1\\) から取る**（初期2点のうち \\(x_0\\) を入れない）。
初期点は誤差の漸化式に乗っていないので、入れると問題によって傾きが目に見えてずれる。

## Rust の言語機構

### 関数を受け取る形

\\(f\\) をどう受けるかに選択肢がある。それぞれ**別の型システム上の意味**を持つ。

```rust
fn a<F: Fn(f64) -> f64>(f: F) {}   // ジェネリック（静的ディスパッチ）
fn b(f: &dyn Fn(f64) -> f64) {}    // トレイトオブジェクト（動的ディスパッチ）
trait Scalar { fn eval(&self, x: f64) -> f64; }  // 自前のトレイト
```

- ジェネリックは呼び出しごとに単相化され、`f` の中身がインライン展開されうる。
  速い代わりに、呼び出した型の数だけコードが生成される（コード膨張とコンパイル時間）。
  戻り値やフィールドに持つと型パラメータが伝播する
- `&dyn Fn` は vtable 経由の間接呼び出しで、インライン化されない。
  コードは1つで済み、`Vec<Box<dyn Fn(f64)->f64>>` のように異種の関数を集められる
- 自前のトレイトは、関数呼び出し以外のものを一緒に要求できる。
  たとえば「値と導関数の両方を返せる」という制約は `Fn` では表現できない

3番目が効いてくるのが次の項である。

### 導関数をどう渡すか

Newton 法は \\(f\\) と \\(f'\\) の両方が要る。渡し方に選択肢がある。

1. 別引数のクロージャで受ける。素直だが、呼び出し側が \\(f'\\) を手で導出する。
   **\\(f\\) と \\(f'\\) が食い違っても型は通る**——手で書いた導関数が間違っていて
   収束しない、は実際によく起きる
2. 数値微分で内部生成する。呼び出し側は楽だが、[自動微分](ch06-autodiff.md)で見るとおり
   差分の精度は最良でも \\(u^{2/3} \approx 10^{-11}\\)（中心差分）程度に留まる。
   2次収束が途中で頭打ちになる
3. dual number を渡す。\\(f\\) を `Fn(Dual) -> Dual` として受ければ、
   演算子オーバーロードだけで \\(f'\\) が同時に出る。**食い違いが原理的に起きない**

3番目が[自動微分](ch06-autodiff.md)である。ここでは素朴でよいが、[自動微分](ch06-autodiff.md)に来たときに
「この章の `newton` を書き換えずに dual 版が使えるか」が、この章で選んだ受け取り方の
評価になる。今の選択が後で試される、という形で覚えておくとよい。

### 失敗をどう返すか

`Result<f64, E>` の `E` に何を入れるか。候補は「収束しなかった」「導関数がゼロ」
「区間の端で符号が同じ」など。

ここで問いが一つある。「反復上限に達したが、現在の推定値は \\(x_{42}\\) である」を
返したいとき、`Result` は正しい形か。`Err` に推定値を積むこともできるし、
`Ok` に収束フラグを付けた構造体を返すこともできるし、
反復列を `Iterator` として出して呼び出し側に止めさせることもできる。
最後の形は[常微分方程式](ch04-ode.md)の適応刻みで同じ問題として戻ってくる。

### `f64` 固定か generic か

`num_traits::Float` で generic にすると `f32` と `f64` の両方で動く。代償は実際に払うまで分かりにくい:

- リテラルが書けない。`2.0` と書けず `T::from(2.0).unwrap()` になる
- 定数（`EPSILON`、`PI`）がトレイト経由になる
- エラーメッセージが長くなる

**`f32` を本当に使うのか**を先に決めるとよい。数値計算では倍精度が既定で、
単精度は GPU かメモリ帯域が律速のときに出てくる。この本の範囲では出てこない。

## オラクル

検証済みの値。scipy は現時点で未導入なので、この章は解析解と厳密な値で足りる。

| 問題 | 根 | 備考 |
|---|---|---|
| \\(\cos x = x\\) | `0.7390851332151607` | Dottie number |
| \\(x^2 - 2 = 0\\) の正根 | `std::f64::consts::SQRT_2` | 解析解 |
| \\(x^3 - 2x - 5 = 0\\)（\\([2,3]\\)） | `2.0945514815423265` | Newton の歴史的な例。残差は評価順に依存する（下記） |
| \\((x-1)^2 = 0\\) | `1.0` | 重根。因数分解形で書けば \\(e_{n+1} = e_n/2\\) ちょうど（下記） |
| \\(x^3 - 2x + 2 = 0\\)（\\(x_0 = 0\\)） | — | Newton が \\(0 \to 1 \to 0 \to 1\\) の**厳密な2周期**に落ちる |
| \\(\arctan x = 0\\)（\\(x_0 = 2\\)） | `0.0` | Newton が発散する。符号が交互に変わりながら桁が増えていく |

不動点反復の収束比の照合用: \\(g(x) = \cos x\\) は \\(g'(x^\*) = -\sin(0.7390851332151607) = -0.6736120291832148\\)。
**実測の収束比がこの値に一致するはずである。**

### オラクルを使うときの罠

**残差は評価順に依存する。** \\(x^3-2x-5\\) を根 `2.0945514815423265` で評価すると、
`r*r*r - 2.0*r - 5.0` と Horner 形 `(r*r - 2.0)*r - 5.0` で結果が違う。
どちらも \\(\mathrm{ulp}(x^\*)\\) の数倍のオーダーだが、同じ値にはならない。
[浮動小数点と丸め](ch00-float.md)で Horner を勧めている以上、読者は後者で書く。
残差を突き合わせるなら評価形を固定するか、\\(\mathrm{ulp}\\) の数倍を許す幅で書く。

**重根は式の書き方で挙動が変わる。** \\((x-1)^2\\) を `(x-1.0)*(x-1.0)` と書けば
理論どおり \\(e_{n+1}=e_n/2\\) が出るが、展開形 `x*x - 2.0*x + 1.0` で書くと
\\(x = 1 + 2^{-27}\\) 付近で**反復が永久に停滞する**。
展開形では根の近傍で \\(f\\) の計算に桁落ちが起き、有効桁が半分になるからで、
[浮動小数点と丸め](ch00-float.md)の二次方程式の桁落ちで出た定数もちょうど \\(2^{-27}\\) だった。由来は別だが
（あちらは \\(\mathrm{ulp}(10^8)\\) の半分、こちらは \\(\sqrt\varepsilon\\) 相当の停滞幅）、
どちらも有効桁が半分になる現象である。
どちらで書くかを決めてから測ること。

### Newton が壊れる例

上の表の下2行がそれである。

\\(x^3-2x-5\\) は**この用途には使えない**。実根が1つで \\(x > 0\\) で凸であり、
初期値を広く振っても吸引周期点は見つからず、すべて収束する。
臨界点 \\(x=\sqrt{2/3}\\) から始めても、一度大きく飛んだあと戻ってくる。
ただし戻ってくるまでに反復回数が跳ね上がる初期値があるので、
「Newton の収束は局所的にしか保証されない」ことを見る例としてなら使える。

2. スカラーを `f64` 固定にするか `num_traits::Float` で generic にするか
3. 導関数の渡し方（[自動微分](ch06-autodiff.md)の伏線として、ここでは素朴でよい）
4. 停止条件をどれにするか、呼び出し側が選べるようにするか
5. 失敗をどう表現するか。「収束しなかったが最善の推定値はこれ」を返す形はどれか

## 完了条件

実装した各手法の収束次数を実測して理論値と一致させ、スケールに依らない不変量を
`proptest` で検査する。

「収束次数を実測する」の注意を守ったうえで、**問題を指定して**測る。指定しないと理論値は出ない。

| 手法 | 使う問題 | 期待する傾き |
|---|---|---|
| 二分法 | \\(\cos x - x\\), \\([0,1]\\) | ≈1 |
| Newton | \\(x^3-2x-5\\), \\(x_0=3\\) | ≈2 |
| 割線 | \\(\cos x - x\\) または \\(e^x-3\\) | ≈1.618 |
| Newton・重根 | \\((x-1)^2\\)、因数分解形 | ≈1 |

二分法は傾きこそ1に乗るが、点は直線ではなく雲になる。誤差比は 1 の上下に1桁以上振れ、
回帰の切片も収束比 \\(1/2\\) から予想される \\(\log(1/2)\\) とは一致しない。
これは実装の誤りではない——前述の R-線形収束の帰結である。

最後の完了条件は `proptest` だが、**不変量の選び方を間違えてはいけない。**
「返された根 \\(x\\) について \\(|f(x)| < \text{tol}\\)」は、この章の停止条件の表で
自分が「壊れる」と書いた条件そのものである。実際 \\(f\\) を \\(10^6\\) 倍しただけで
\\(|f(x)|\\) が \\(10^{-10}\\) のオーダーになり `tol = 1e-10` を通らない。逆に \\((x-1)^2\\) では
\\(x = 1+10^{-8}\\) が \\(|f| = 10^{-16}\\) で合格してしまう。

スケールに依らない不変量を選ぶ。二分法・Brent なら次が真に成り立つ。

- 返り値が初期区間 \\([a,b]\\) の中にある
- 初期区間の符号変化が最後まで保たれている
- 最終区間の幅が `tol` 以下

これが性質ベーステストの使いどころで、個別の入力に対する正解を用意せずに広い入力空間を叩ける。
この先でも同じ形が出る（作用素の線形性は[求積](ch03-quad.md)、往復は[FFT と Monte Carlo](ch07-fft-mc.md)、\\(PA = LU\\) の再構成は[密行列の線形代数](ch02-linalg.md)）。
ただし**不変量が本当に不変かは毎回考える必要がある**、という教訓がここに付く。
