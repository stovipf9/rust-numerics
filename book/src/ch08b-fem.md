# 有限要素法

章8の後半。差分法で von Neumann 安定性と CFL を見た後で読む。

Rust の設計緊張はこちらが本体である。疎行列のインデックス構造、
メッシュという相互参照グラフ、並列アセンブリの競合、matrix-free の抽象——
4つとも差分法には出てこない問題である。

## 有限要素法

### 弱形式

Poisson 方程式 \\(-u'' = f\\)（\\(u(0)=u(1)=0\\)）に、
テスト関数 \\(v\\)（境界でゼロ）を掛けて積分し、**部分積分する。**

\\[
\int_0^1 u'v'\,dx = \int_0^1 fv\,dx \qquad \forall v
\\]

**2階微分が1階に下がった。** これが弱形式の要点である。得られるものは2つ。

1. \\(u\\) に要求される滑らかさが下がる（\\(C^2\\) から \\(H^1\\) へ）。
   区分1次多項式が使えるようになる
2. 対称な形になり、\\(A\\) が対称正定値になる——Cholesky と共役勾配法が使える（章2）

### Galerkin 法

解を基底 \\(\\{\phi_i\\}\\) の線形結合 \\(u_h = \sum_j c_j\phi_j\\) で近似し、
テスト関数も同じ基底から取る。弱形式に代入すると

\\[
\sum_j c_j \underbrace{\int \phi_i'\phi_j'\,dx}\_{A_{ij}} = \underbrace{\int f\phi_i\,dx}\_{b_i}
\\]

**線形方程式 \\(Ac = b\\)。** \\(A\\) を**剛性行列**という。

一意可解性は Lax–Milgram の定理から出る（双線形形式の連続性と強圧性）。
そして近似解の誤差は **Céa の補題**により、
\\(\\|u - u_h\\|_{H^1} \le C \inf_{v_h} \\|u - v_h\\|_{H^1}\\)——
つまり**「その空間で取れる最良近似の定数倍」**で押さえられる。
あとは補間誤差の評価（章2c）を入れれば次数が出る。この道筋（Lax–Milgram → Céa → 補間誤差）が
FEM の誤差評価の骨格である。

もう1つ、時間依存問題では**質量行列** \\(M_{ij} = \int\phi_i\phi_j\,dx\\) が出る。
半離散化すると \\(M\,\dot c = -Ac + b\\) という形になり、
差分法の \\(\dot u = Au\\) と違って**左辺に行列が付く**（一般固有値問題になる）。
下の不変量で使うので定義しておく。

### 疎性はどこから来るか

区分1次の基底（帽子関数）は局所台を持つ——\\(\phi_i\\) は節点 \\(i\\) の隣接要素の上でだけ非ゼロ。
したがって \\(\phi_i'\phi_j'\\) の積分は台が重なる \\((i,j)\\) でしか非ゼロにならない。

基底の局所性が、そのまま行列の疎性になる。
1次元なら三重対角、2次元三角形要素でも1行あたり数個にとどまる。
FEM が大規模問題に使えるのは、この構造があるからである。

## Rust の言語機構

### 疎行列——インデックス構造を所有する

密行列は `Vec<f64>` と形だけで表せた。疎行列はインデックス配列が絡む。

| 形式 | 構造 | 向き |
|---|---|---|
| COO | `(row[], col[], val[])` の三つ組 | 組み立て向き。重複を許して後で潰す |
| CSR | `(row_ptr[], col_idx[], val[])` | 行ごとのアクセス、行列ベクトル積 |
| CSC | 列版 | 列ごとのアクセス、直接法ソルバー |

アセンブリは COO で作り、解く前に CSR へ変換するのが定石である。
COO は追加が \\(O(1)\\) だが積が遅く、CSR は積が速いが追加ができない。
**「組み立て中」と「解く」で別の型にする**のが Rust らしい表現で、
`from_coo(coo) -> Csr` のような変換で所有権を移せば、
**組み立て済みの行列に誤って追加する**ことが型で防げる。

疎行列クレートは集約していない——`sprs` / `nalgebra-sparse` / `faer` の `sparse` モジュール。
`faer` は solvers まで持っており、章2で `faer` を選んでいればここが繋がる。
（単体の `faer-sparse` クレートは 2024-02 で止まり、本体に統合済みである。）

### メッシュ——章6と同じ問題

要素は節点を参照し、節点は接続する要素を知りたい。隣り合う要素は辺を共有する。
相互参照するグラフである。

`Rc<RefCell<Node>>` で組むと循環参照が生まれ、解放されない。
**Rust の定石はインデックス方式**で、

```rust
struct Mesh {
    coords: Vec<[f64; 2]>,      // 節点 i の座標
    elements: Vec<[usize; 3]>,  // 要素 e の3節点を「番号」で
}
```

節点も要素も1本の `Vec` に連続して乗り、参照は `usize`。
**章6の autodiff のテープとまったく同じ構造である。**
`slotmap` の型付きハンドルを使えば「節点番号を要素番号として渡す」誤りが型で防げるし、
`petgraph` は隣接関係のクエリを持っている。

**同じ道具で章6とこの章の両方が解ける**——汎用の道具で複数の問題を解く形になっている。

### 並列アセンブリ——型システムが競合を弾く

剛性行列は要素ごとの局所行列を、全体行列の対応する位置に足し込むことで作る。
要素ループは独立に見えるので `rayon` で並列化したくなる。

**が、隣り合う要素は節点（自由度）を共有する。**
2つの要素が同じ \\(A_{ij}\\) に同時に加算しようとする——データ競合である。

```rust
// これはコンパイルが通らない
elements.par_iter().for_each(|e| {
    a[i][j] += local(e);   // &mut a を複数スレッドが同時に要求する
});
```

**C++ なら通って、たまに答えが変わる。** Rust では `&mut` を複数スレッドに配れないので、
**コンパイルの時点で止まる。** 「不可能な並列化を型システムが弾く」ことを
実感する最良の題材である。

逃げ方は3つあり、それぞれ別のものを代償にする。

| 逃げ方 | メモリ | 前処理 | 結果の再現性 |
|---|---|---|---|
| 局所行列を全部作ってから reduce | 要素数ぶん食う | 不要 | reduce の木の形で変わる |
| 色分け（graph coloring） | 増えない | 彩色が要る | **決定的**（加算順が固定される） |
| 行ごとに分割して `Mutex` / ロック | 増えない | 不要 | ロック取得順で毎回変わりうる |

**4列目が章0の伏線の回収である。** 浮動小数点の加算は結合的でないので、
加算の順序が変わると結果のビットが変わる。`rayon` の分割はワークスティール依存なので、
1行目と3行目は**実行ごとに答えが変わりうる**。色分けだけが決定的である。

つまり再現性は、メモリ・前処理・ロック競合と並ぶ**第4の評価軸**である。
**どれを選ぶかは測ってから決める**類の判断だが、再現性が要件なら選択肢が先に絞られる。

### matrix-free

章2で見たとおり、**共役勾配法は \\(A\\) そのものを要求しない。**
必要なのは \\(v \mapsto Av\\) だけである。

FEM では \\(Av\\) を「要素ごとに局所行列を掛けて足す」形で、
**全体行列を一度も組み立てずに計算できる。** メモリが劇的に減り、
大規模問題では組み立てるほうが不可能になる。

**この事実をトレイトで表現する**のがこの章の設計の山場である。

```rust
trait LinearOperator {
    fn apply(&self, v: &[f64], out: &mut [f64]);
    fn dim(&self) -> usize;
}
```

疎行列も、組み立てないメッシュも、同じトレイトを実装する。
**CG は `impl LinearOperator` に対して generic に書けているか**——
章2で CG を書いたときに `&SparseMatrix` を直接受けていたら、ここで書き換えになる。

`faer` に `matrix_free` モジュールがあるので、**実例を読んでから自分の設計と比べる**とよい。

### FEM のデファクトは存在しない

`fenris` は利用も更新も止まっており、事実上停止している。
**既製品を呼ぶ選択肢が無く、自分で書くのが唯一の道である。**
疎行列と線形ソルバーは既製品を使えるので、書くのはメッシュとアセンブリになる。


## オラクル

### 1次元 Poisson

\\(-u'' = f\\)、\\(u(0)=u(1)=0\\):

| \\(f\\) | 解 |
|---|---|
| \\(1\\) | \\(u = x(1-x)/2\\) |
| \\(\pi^2\sin(\pi x)\\) | \\(u = \sin(\pi x)\\) |
| \\(x\\) | \\(u = (x - x^3)/6\\) |

区分1次要素の \\(L^2\\) 誤差は \\(O(h^2)\\)、\\(H^1\\) 誤差は \\(O(h)\\)。
ただし**仮定が要る**——\\(u \in H^2\\)（1次元なら \\(f \in L^2\\) で足りる）と、
メッシュが準一様であること。2次元で凸でない領域や re-entrant corner があると
解の正則性が落ちて2次は出ない。

### 節点で測ると次数は出ない

1次元の P1 要素は**節点で厳密**である（超収束）。
要素上で測れば \\(L^2\\) 誤差に \\(O(h^2)\\)、\\(H^1\\) 半ノルム誤差に \\(O(h)\\) の次数が見えるのに、
節点の最大誤差はメッシュを細かくしても丸めの水準に張り付いたままになる。

節点誤差は丸めだけで決まり、**\\(h\\) に対する収束次数を持たない**（増えも減りもする）。
上界としては \\(u\,\kappa(A) = O(uN^2)\\) だが、実際にはそれよりずっと小さく、
ソルバーと荷重ベクトルの求積の実装に依存する。
素直に `max|u_h[i] - u(x_i)|` を測ると
次数が出ないので、ここで詰まる。必要なのは3つ:

1. \\(L^2\\) 誤差は**要素上の求積で計算する**。\\(\int_0^1 (u-u_h)^2\\) を
   各要素で Gauss–Legendre（章3）で積む。**ここが章3への依存である**
2. これは1次元 P1 の特殊事情で、2次元では成り立たない
3. 荷重ベクトル \\(\int f\phi_i\\) を低次の求積で近似すると次数が落ちる。
   求積の次数も設計判断になる

### 不変量

- 剛性行列が**対称**（\\(A = A^\top\\)）
- 剛性行列が**正定値**（境界条件を課した後）
- 剛性行列の**行和がゼロ**（境界条件を課す前。\\(\sum_j\phi_j \equiv 1\\) から \\(\sum_j A_{ij} = \int\phi_i'\cdot 0 = 0\\)）
- 質量行列 \\(M_{ij} = \int\phi_i\phi_j\\) の全成分の和が領域の測度に等しい
  （\\(\sum_{ij}M_{ij} = \int(\sum\phi_i)(\sum\phi_j) = \int 1 = |\Omega|\\)）。
  **これも境界節点の基底を含めて初めて成立する**——内部自由度だけに落とすと
  \\(1 - 4/(3N)\\) になる

**上2つは境界条件の課し方に依存する。** 行を \\(e_i^\top\\) に置き換える「行を潰す」方式は
**対称性を壊す**ので、対称・正定値の不変量が成立しない。成立するのは
「未知数から除く」か「対称化した行潰し」のときだけである。
つまり下の決めること5は、**どの不変量をテストに使えるかを決める判断でもある。**

## この章で決めること

1. 疎行列を自作するか `sprs` / `nalgebra-sparse` / `faer` を使うか。
   COO と CSR を別の型にするか
2. メッシュをインデックス方式で組むか。`slotmap` / `petgraph` を使うか、
   `Vec` + `usize` を自分で書くか
3. アセンブリの並列化をどの逃げ方でやるか（局所行列 + reduce / 色分け / ロック）。
   再現性を要件にするかどうかで選択肢が絞られる
4. `LinearOperator` トレイトを切るか。章2の CG がそれに対して generic か
5. 境界条件をどう課すか（行を潰す / ペナルティ / 未知数から除く）。
   これが使える不変量を決める
6. \\(L^2\\) 誤差の求積に章3のどの公式を使うか。荷重ベクトルの求積の次数をいくつにするか

## 完了条件

**1次元 Poisson を FEM で解いて解析解と一致させ、\\(L^2\\) 誤差の次数が \\(O(h^2)\\)、
\\(H^1\\) 誤差の次数が \\(O(h)\\) になることを実測する。**

節点値で測ってはいけない（前述。P1 は節点で厳密なので次数が出ない）。
要素上の求積で \\(L^2\\) ノルムを計算する。

不変量のほうは `proptest` で検査する。境界条件の課し方によって
使える不変量が変わるので、そこを意識して選ぶ。

2次元三角形要素まで到達できれば十分である。

ここまで来れば、章2の線形代数（CG と Cholesky）・章3の求積・章4の時間積分・
章6の所有権設計が、全部1つの問題の上で動いていることになる。
